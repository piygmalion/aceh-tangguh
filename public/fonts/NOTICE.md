# Glyphs

MapLibre glyph ranges for `Noto Sans Regular`, self-hosted so the basemap does not call a public glyph server.

- Font: Noto Sans, Copyright The Noto Project Authors
- License: SIL Open Font License 1.1 — https://openfontlicense.org/
- PBF ranges vendored from the Protomaps basemaps-assets font build: https://github.com/protomaps/basemaps-assets
- Ranges: `0-255`, `256-511`, `512-767`, `768-1023`, `8192-8447`
- No sprite atlas. The basemap style uses text labels only.
