## Niat

- Tujuan: Menuliskan nama `OVERLAY_CRON_SECRET` / `OVERLAY_REFRESH_URL` di `.env.example` (tanpa nilai). Mengisi variabel GitHub `OVERLAY_REFRESH_URL` dengan URL produksi yang sudah tertulis di `docs/vercel.md`. Jangan membuat atau menulis nilai secret. Jangan POST ke cron. Rapikan satu kalimat README: seed `upsert_marker_features` wajib `service_role`.
- Berkas: `.env.example`, `README.md` (satu kalimat seed), jurnal, STATUS. Variabel GitHub (bukan berkas).
- Tidak diubah: rute cron, `overlay-live.ts`, Vercel secret, DATA-4, P2 Juklak, `messages/**`.
- Langkah:
  1. Tambah komentar nama overlay di `.env.example` (pola cuaca).
  2. `gh variable set OVERLAY_REFRESH_URL` = `https://aceh-tangguh.vercel.app/api/cron/overlay-live` jika belum ada.
  3. Jangan `gh secret set OVERLAY_CRON_SECRET`. Jangan `workflow_dispatch`.
  4. README: hapus klaim “tidak memerlukan service_role”.
- Cara membuktikan: `.env.example` memuat kedua nama; `gh variable list` memuat `OVERLAY_REFRESH_URL`; `gh secret list` tidak menambah secret dari tiket ini; README menyebut service_role.
- Risiko: mengarang nilai secret; memutar secret yang ada; POST cron; DATA-4.

## Bacaan ulang niat

Nama + URL publik. Secret tetap diisi operator di Vercel + GitHub. Workflow tetap skip jika secret kosong.
