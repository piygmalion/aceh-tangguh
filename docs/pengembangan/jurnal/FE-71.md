Agent: frontend

## Niat

- Tujuan: Gelembung undangan Tanggapi di telepon (<768) duduk di atas tombol FAB, ekor menunjuk ke FAB, tanpa menutup kicker, judul, CTA, atau judul grafik "Kejadian per tahun". Chip panduan satu baris yang digulir. Header kartu peta lebih pendek saat badan tergulir supaya badan kartu di 390×844 minimal sekitar 200px. Membuka Panel layer di bawah 768 menutup popup. Pegangan panel tidak melewati tepi bawah. "Laporkan" di menu 390 sejajar tautan lain.
- Berkas: `GuideBot.tsx`, `GuidePanel.tsx`, `MapFeatureCard.tsx`, `MapViewport.tsx`, `MapToolbar.tsx`, `SiteNav.tsx`, `ReportLaporDropdown.tsx`, `src/lib/fe-71-visual-4.test.ts`, jurnal dan `report.json`.
- Langkah: Lepas pin `top-24`. Chip `overflow-x-auto` tanpa bungkus, target 44px. Sembunyikan baris kicker saat badan kartu tergulir. Tutup popup lewat acara saat panel terbuka, fokus kanvas tanpa `setAttribute tabindex`. `safe-area-inset-bottom` pada pegangan. Bentuk baris untuk Laporkan di laci.
- Cara membuktikan: `npm test`, `npm run lint`, `npm run build`. Tangkapan di `docs/pengembangan/jurnal/fe-71/`.
- Risiko: Gelembung di atas FAB menimpa label batang. Header yang disembunyikan membuat judul hilang. Menu desktop ikut berubah.

## Bacaan ulang niat

Gelembung desktop tetap di kolom di atas FAB. Yang diubah hanya telepon: tidak lagi `fixed` di bawah header. Judul kartu tetap lengket; yang hilang saat gulir adalah baris kicker (ikon + kategori) dan subjudul, bukan judul. Desktop Laporkan tetap bentuk pill. `RisikoLadder.tsx` dan `peta-teaser-paths.ts` tidak disentuh. Tidak ada API, env, fixture, ubin, atau gaya peta.
