## Naskah (overlay env + halaman publik)

Satu perilaku per butir. Jangan menulis nilai secret. Jangan menulis langkah serangan.

### 1. Nama env overlay

**Perilaku.** `.env.example` memuat nama `OVERLAY_CRON_SECRET` dan `OVERLAY_REFRESH_URL` tanpa nilai. Pola sama dengan cuaca.

### 2. Variabel GitHub URL

**Perilaku.** Variabel repositori `OVERLAY_REFRESH_URL` = URL yang sudah tertulis di `docs/vercel.md` (`https://aceh-tangguh.vercel.app/api/cron/overlay-live`). Bukan secret.

### 3. Secret masih operator

**Perilaku.** `OVERLAY_CRON_SECRET` tetap diisi operator di Vercel dan GitHub Actions. Jika kosong: workflow mencetak skip dan keluar 0; `POST /api/cron/overlay-live` tetap 503. GET overlay live tetap 503 jika ledger kosong (BE-8). Jangan `workflow_dispatch` dari tiket ini. Jangan menulis nilai.

### 4. Tiga halaman publik

**Perilaku.** `/[locale]/pelatihan`, `/nomor-penting`, `/mitra` tidak hardcode judul Indonesia. Salinan lewat `publik` + `nav.home`. Locale `en` memakai path `/training`, `/emergency-contacts`, `/partners`.

### 5. Non-tujuan

**Perilaku.** Jangan DATA-4. Jangan POST nasional. Jangan membuka P2 Juklak. Jangan meni18n-kan daftar/form di dalam komponen. Jangan POST ke cron overlay.
