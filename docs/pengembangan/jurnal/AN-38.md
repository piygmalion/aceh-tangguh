# AN-38 — naskah Aceh Disaster Daily Brief (staf)

Agent: analis

Status: selesai

Tulisan. Bukan kode pada tiket ini. Jangan menimpa AN-4, AN-24, AN-36, AN-37, FE-38, atau DATA-4. DATA-24 / BE-29 / FE-39 / AN-39 menjalankan naskah ini setelah bacaan ulang.

## Niat

- Tujuan: Mengunci saluran **ringkasan harian staf** (compose dari umpan hidup + WhatsApp + halaman `/brief/[ymd]`) supaya tidak jadi siaran publik, tidak mengarang angka, dan tidak membuka stack Python/OTP.
- Berkas: jurnal ini; baris G31 di `STATUS.md`, `00-protokol.md`, brief `01`–`04`. Tiket ini tidak menyunting `src/`.
- Langkah: tulis aturan tunggal per butir; baca ulang; jangan menebak `loggerKind`, zona KRB, atau angka korban.
- Cara membuktikan: setiap butir adalah aturan. DATA/BE/FE dapat dijalankan tanpa menebak audiens, secret, kosong vs tertunda, atau PII.
- Risiko: menyalin konsep Downloads (OTP publik, Z-API, HTML CDN) sebagai SoT; mengisi hitungan gempa saat overlay gagal; menimpa AN-37.

## Bacaan ulang niat

Naskah ini membuka WhatsApp **hanya** ke nomor yang ditambah operator provinsi. AN-37 tetap menutup siaran ke publik. Compose G31 tidak memakai LLM. Riset AI = Gelombang 32, jangan dikode di sini. Sumber = umpan yang sudah ada, bukan BMKG/BNPB nasional baru.

## Naskah

### 1. Saluran

**Perilaku.** Satu pesan WhatsApp per hari ke subscriber berstatus `active`. Bukan form publik, bukan OTP, bukan tabel `users`. Bukan baris `notifikasi_wa` laporan. Antrean terpisah (`daily_brief_message_logs`). Template baru `daily_brief` di `whatsapp.ts`; template laporan tidak diubah.

### 2. Otorisasi

**Perilaku.** CRUD nomor, generate manual, dan enqueue ulang = `isProvinsiOps` (`super_admin` / `admin_provinsi` / legacy `admin`). `admin_kabkota` dan peran lain = 403. Halaman `/admin/daily-brief` memakai `SikForbidden` jika bukan provinsi. GET `/api/brief/[ymd]` dan halaman `/brief/[ymd]` publik baca; tubuh tanpa nomor, tanpa `phone_enc`.

Modul `dailyBrief` di `canAccessModule`: hanya `super_admin` dan `admin_provinsi`.

### 3. Jadwal dan secret

**Perilaku.** Cron `00 0 * * *` UTC = 07:00 WIB. Rute `POST /api/cron/daily-brief`. Secret `DAILY_BRIEF_CRON_SECRET` (nama saja). Unset → 503. Bearer salah → 401. Jangan reuse `OVERLAY_CRON_SECRET`, `WEATHER_*`, atau `LAPORAN_CRON_SECRET`. GitHub var `DAILY_BRIEF_URL`. Workflow skip-if-unset. Idempoten per `brief_date` kalender `Asia/Jakarta`: baris ada + `whatsapp_enqueued_at` terisi → jangan compose ulang kecuali generate staf `force`.

### 4. Compose

**Perilaku.** Field ringkasan hanya dari umpan `source: "live"` yang bukan `unavailable`. Satu umpan mati tidak diisi dari umpan lain.

| Umpan | Live + empty | `unavailable` / query gagal | Stale + ada isi |
| --- | --- | --- | --- |
| Cuaca / MAGMA / Sipongi / Tatonas | Kalimat kosong sah dari kartu | `availability: "unavailable"`, headline “data tertunda”, tanpa angka | Boleh salin highlight + catat tertunda |
| Gempa overlay `bmkgQuakes` | `count` = jumlah baris cache dengan `occurred_at` pada `brief_date` Jakarta (0 sah) | `available: false`, jangan tulis `0` | — |
| Kejadian / `live_stats` | `activeIncidents` hanya jika baris ada | Jangan isi | — |

Jangan DIBI, IRBI, proyeksi dampak, WeatherNext, buletin maritim (AN-36), angka korban, zona KRB, atau `loggerKind`. Tatonas: jumlah highlight kartu saja, tanpa jenis logger.

### 5. Pesan WA

**Perilaku.** Teks + tautan `/{locale}/brief/{yyyy-mm-dd}` (`todayJakartaYmd`). Disclaimer wajib: ringkasan umpan situs, bukan saluran darurat; darurat 112 / Pusdalops. Locale tautan default `id`.

### 6. PII

**Perilaku.** Nomor lewat `encryptPii` / `normalizeWhatsAppPhone`. RLS subscriber + log: anon dilarang; tulis lewat service role setelah gerbang provinsi. `daily_briefs` SELECT publik (tanpa PII). UI daftar menampilkan nomor mask. Export CSV hanya `isProvinsiOps`.

### 7. Status nomor

**Perilaku.** `active` / `inactive` / `unsubscribed`. Toggle admin. Jangan hapus keras tanpa baris log. Kata kunci balasan inbound = G32 jika gateway punya webhook; G31 tidak mengarang inbound.

### 8. Non-tujuan

**Perilaku.** Jangan AN-36, AN-4 / `CALON_LAYER_KEYS`, FE-38 / compiler Tanggapi, DATA-4, POST nasional, P2 Juklak, merge `/api/weather`, HTML file sebagai SoT, stack Python/Z-API/JWT baru, menaikkan kuota Tanggapi 20/jam. Gelombang 32 (AN-40 / DATA-25 / BE-30 / FE-40) jangan dikode.
