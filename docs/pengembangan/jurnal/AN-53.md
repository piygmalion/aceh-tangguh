# AN-53 — naskah verifikasi email staf (undang → tautan → set sandi)

Agent: analis
Gelombang: tindak lanjut (bukan G31/G33/G36)
Status: selesai

Tulisan. ID rencana `AN-44` / `AN-45` / `FE-50` / `BE-34` sudah terpakai (Tanggapi, konsep error/auth/rate-limit, pager). Kontrak ini untuk BE-38 / FE-53 / AN-54. Jangan menimpa AN-41, AN-44 Tanggapi, FE-49, FE-50 pager, FE-52, G36.

## Niat

- Tujuan: Mengunci alur Super Admin mengundang staf, staf membuka tautan email, sesi terbentuk, staf menyetel kata sandi — tanpa OTP publik dan tanpa tabel token sendiri.
- Berkas: jurnal ini. Koordinator menambah STATUS / brief. Tiket ini tidak menyunting `src/` kecuali AN-54.
- Langkah: satu aturan per butir; baca ulang; jangan mengarang email.
- Cara membuktikan: BE/FE dapat dijalankan tanpa menebak `redirectTo`, jenis OTP, atau halaman set sandi.
- Risiko: `signInWithOtp` publik; PKCE pada invite admin; kolom baru `admin_profiles`; merevoke `is_staff` / `is_ops`.

## Bacaan ulang niat

Adopt Auth Supabase yang sudah dipakai `inviteUserByEmail`. Konfirmasi memakai `token_hash` + `verifyOtp` jenis `invite` atau `email`. Status konfirmasi dari `email_confirmed_at` Auth Admin, bukan migrasi. Login password yang sudah hidup tetap. Pelapor `/lapor` tidak berubah.

## Naskah

### 1. Aktor

**Perilaku.** Undang dan kirim ulang: hanya `super_admin` (`requireSuperAdminApi`) + `rejectCrossOrigin` pada POST. Halaman `/admin/set-password` untuk pengguna yang baru lolos `verifyOtp` (ada sesi). Tanpa sesi → `/admin/login`. Jangan password di body undangan. Jangan seed email.

### 2. Undang

**Perilaku.** `POST /api/admin/users` tetap katalog AN-41. Wajib `redirectTo` absolut `{origin}/auth/confirm`. Origin dari header Origin yang sudah lolos host, atau host permintaan, atau `https://aceh-tangguh.vercel.app`. Jangan origin bebas. Insert profil + rollback `deleteUser` tetap.

### 3. Konfirmasi

**Perilaku.** `GET /auth/confirm` di luar `[locale]`. Query: `token_hash` (wajib), `type` hanya `invite` atau `email`. Selain itu, token kosong, atau `verifyOtp` gagal → redirect `/{locale}/admin/login?error=invite_invalid` (pesan generik; jangan bocorkan apakah email ada). Sukses → cookie sesi + redirect `/{locale}/admin/set-password`. Locale query `id`|`en`, default `id`. `next` hanya path `/admin/set-password` (bukan URL absolut). Rate limit per IP memakai helper yang sudah ada (bukan paket baru). Jangan `signInWithOtp`. Jangan PKCE pada jalur undangan.

### 4. Set sandi

**Perilaku.** Pathname `/admin/set-password` (ID+EN sama). Form `updateUser({ password })` di klien cookie. Sukses → `/admin`. i18n `admin.*`. Bukan di `(console)` (hindari `requireStaffPage` sebelum sandi tersimpan, meski profil mungkin sudah ada).

### 5. Daftar + kirim ulang

**Perilaku.** `GET /api/admin/users` menambah `emailConfirmed: boolean` dari `email_confirmed_at` (jangan kirim token). Chip: belum konfirmasi memakai kunci `staffPending`; aktif `staffActive`; tangguh `staffSuspended`. `POST /api/admin/users/[id]/resend-invite`: super_admin + origin; target tidak ada → 404; `email_confirmed_at` terisi → 409 `already_confirmed`; selain itu `inviteUserByEmail` lagi dengan `redirectTo` yang sama. Jangan mengarang email.

### 6. Operator (bukan kode)

Confirm email nyala. Public signup mati. Redirect URLs: `https://aceh-tangguh.vercel.app/auth/confirm` + preview. Templat Invite: tautan ke `/auth/confirm?token_hash={{ .TokenHash }}&type=invite`. Jangan menulis nilai SMTP.

### 7. Non-tujuan

Bukan OTP publik. Bukan pelapor. Bukan tabel `email_verification_tokens`. Bukan Resend/SMTP baru di repo. Bukan DATA-4. Bukan POST nasional. Bukan P2 Juklak. Bukan merevoke helper SQL. Bukan G32. Bukan menimpa FE-50 pager / FE-52.
