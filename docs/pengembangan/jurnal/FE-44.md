Agent: frontend
Gelombang: permintaan beranda (bukan gelombang 35)
Status: selesai

## Niat

- Tujuan: Bagian `#status` Peringatan Dini di beranda menjadi slideshow horizontal berisi lima kartu (cuaca, MAGMA, Sipongi, Tatonas, maritim), bukan kisi 3+2. Kartu, tinggi, dan gulir isi tidak berubah.
- Berkas: `src/components/PeringatanDiniSection.tsx`, `messages/id.json`, `messages/en.json` (kunci baru di `peringatanDini` saja), `src/lib/peringatan-dini-section.test.ts`, jurnal ini, `docs/pengembangan/STATUS.md` saat tutup.
- Tidak diubah: `h-[20rem]` + `overflow-y-auto` isi kartu; `logger_kind.toUpperCase()`; fetch `/api/peringatan-dini`; WeatherStrip; FE-43 dasbor operasi; DATA-4; angka korban.
- Search-first: pakai pola karusel yang sudah ada (`aria-roledescription="carousel"`, panah, titik, `prefers-reduced-motion`). Jangan menambah Swiper/Embla/Slick.
- Langkah:
  1. Tulis uji: ada carousel + lima slide; tidak ada `md:grid-cols-2` / `xl:grid-cols-3` pada track kartu; kunci i18n `carouselAria` / `prev` / `next` / `slideOf` di id+en; tinggi+gulir tetap.
  2. Bungkus lima kartu dalam track satu kartu per slide; tombol prev/next + titik; jeda autoplay saat hover/fokus atau reduced-motion.
  3. Skeleton loading satu slide, bukan kisi lima.
- Cara membuktikan: `npm test -- src/lib/peringatan-dini-section.test.ts src/lib/pd-cuaca-sot4-ux.test.ts`; `npm test`; browser `/id#status` dan `/en#status` — lima slide, panah, titik, kartu tetap 20rem.
- Risiko: menimpa kunci i18n lama; merusak SoT-4 tinggi/gulir; autoplay mengganggu gulir isi Tatonas (jeda saat hover/fokus).

## Bacaan ulang niat

Lima kartu tetap lima sumber; urutan cuaca → MAGMA → Sipongi → Tatonas → maritim. Jika `tatonas` atau `maritim` absen, slide itu tidak dibuat (jangan kartu kosong karangan). Satu slide = satu kartu lebar penuh wadah `max-w-6xl`, bukan 2–3 kartu sekaligus (itu masih kisi). Chrome baru hanya label karusel; judul/subtitle/tone yang sudah ada jangan ditimpa. Tombol kontrol `type="button"` di luar `<a>` kartu.
