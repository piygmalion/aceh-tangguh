## Allowlist

### Citra GIBS (browser, tanpa kunci)

Endpoint: `https://gibs.earthdata.nasa.gov/wmts/epsg3857/best/{Layer}/default/{TIME}/{TileMatrixSet}/{z}/{y}/{x}.{ext}`

| Kunci UI `?nasa=` | LayerIdentifier | TileMatrixSet | Format | Keterangan |
| --- | --- | --- | --- | --- |
| `gibsTrueColor` | `VIIRS_SNPP_CorrectedReflectance_TrueColor` | `GoogleMapsCompatible_Level9` | jpg | Wajib |
| `gibsThermal` | `VIIRS_SNPP_Thermal_Anomalies_375m_Night` | `GoogleMapsCompatible_Level8` | png | Opsional, opacity rendah di atas true color |

`TIME` = `YYYY-MM-DD` (hari UTC). Tolak tanggal masa depan (setelah UTC hari ini). Jangan proxy ubin lewat Next. Attribution: NASA EOSDIS GIBS.

Deep-link Worldview (metadata): `https://worldview.earthdata.nasa.gov/` dengan v=ACEH_BBOX, t=tanggal, l=layer allowlist.

GET `/api/nasa-nrt/gibs/time` (publik): `{ defaultDate, source: "utc-yesterday", validation: "unofficial_nrt" }`. Tidak wajib panggil DescribeDomains di G37.

### Titik FIRMS (server)

- Sumber: FIRMS Area API CSV, `VIIRS_SNPP_NRT`, rentang **1 hari** (boleh 2 jika niat BE menulis 2; default 1).
- Area: `west,south,east,north` = `ACEH_BBOX` `[95.0, 2.0, 98.3, 6.15]`.
- Env: `FIRMS_MAP_KEY` hanya server. Jangan `NEXT_PUBLIC_*`.
- NOAA-20 **tidak** di G37 (satu sumber dulu).
- Jangan tulis `overlay_live_features`. Jangan import dari `overlay-calon`.

## HTTP FIRMS — `GET /api/nasa-nrt/firms`

Badan JSON selalu punya `metadata.official === false` dan `metadata.validation === "unofficial_nrt"`.

| Kondisi | HTTP | `metadata.status` | `features` |
| --- | --- | --- | --- |
| Kunci tidak ada | **503** | `unconfigured` | `[]` |
| Hulu gagal / CSV tidak bisa diurai | **503** | `upstream` | `[]` |
| Hulu OK, nol titik di bbox | **200** | `ok` | `[]` (kosong sah) |
| Hulu OK, ada titik | **200** | `ok` | titik parse |

Jangan klaim 503 sebagai “tidak ada hotspot”. Cache L2 `unstable_cache` ~10 menit. Bukan Upstash store. Bukan limiter GET baru.

Field metadata wajib: `fetched_at`, `observed_at` (hari akuisisi atau tanggal permintaan), `source` (`firms-viirs-snpp-nrt`), `validation`, `href` katalog FIRMS, `bbox` salinan ACEH_BBOX.

Properti titik (jangan dikarang jika kolom hilang): `latitude`, `longitude`, `acq_date`, `acq_time`, `confidence`, `frp`, `satellite`, `daynight`.

## URL peta

- `?nasa=` daftar kunci allowlist (`gibsTrueColor`, `gibsThermal`, `firmsHotspots`), default kosong.
- `?nasaDate=YYYY-MM-DD` opsional; invalid → tanggal default.
- **Jangan** token nasa di `?overlays=`. `parseOverlayLayers` membuang `gibsTrueColor` / `firmsHotspots`.
