# FE-72 — map chrome at 390

Agent: frontend
Gelombang: visual
Status: diverifikasi

## Niat

- Tujuan: Di bawah 768, tombol pengaturan dan tombol "+" tidak menutup Panel layer yang terbuka, dan kembali saat panel ditutup. Legenda status di telepon tidak bertabrakan dengan kontrol zoom. "Laporkan" di menu 390 selebar tautan lain (358px) dengan teks tetap mulai di x 28.
- Berkas: `MapWorkspace.tsx`, `MapToolbar.tsx`, `ReportLaporDropdown.tsx`, `src/lib/fe-72-map-chrome.test.ts`, jurnal dan `report.json`.
- Langkah: Naikkan keadaan panel terbuka ke ruang peta dan sembunyikan kedua tombol dengan `max-md:hidden` hanya saat panel terbuka. Geser legenda telepon ke `left-14`. Tombol baris Laporkan `w-full`.
- Cara membuktikan: `npm test`, `npm run lint`, `npm run build`. Tangkapan di `docs/pengembangan/jurnal/fe-72/`.
- Risiko: Desktop ikut tersembunyi. Kanvas kehilangan `tabindex`. Chip status kehilangan garis.

## Bacaan ulang niat

Sembunyi tombol hanya lewat kelas `max-md`, jadi lebar 1440 tetap menampilkan pengaturan dan "+". Legenda desktop di tumpukan bawah tidak digeser. Garis `#111` chip tetap di `StatusScaleChip`. Tidak ada `setAttribute` pada kanvas. Ubin, gaya peta, data, API, env, fixture, `RisikoLadder.tsx`, dan `peta-teaser-paths.ts` tidak disentuh.
