Tulisan, bukan kode. Mengunci konsep dashboard builder agar tiket DATA-23 / BE-29 / FE-32 / AN-37 berjalan tanpa tebakan. ID UI = FE-32 (FE-31 sudah G24). ID data = DATA-23 (DATA-22 sudah tilikan). ID API = BE-29 (BE-28 sudah analisis). Penerimaan = AN-37.

## Niat

- Tujuan: Mengunci kontrak produksi insight/dashboard: objek, registri sumber gelombang 1, mesin kueri adapter (bukan SQL), peran, RLS, terbit, layout, jenis chart, isolasi IRBI/DIBI/PII, rute, kuota, dan kriteria emas.
- Berkas: jurnal ini; `STATUS.md`; `00-protokol.md`; `04-analis.md`; `03-frontend.md`; `02-backend.md`; `01-data.md`.
- Langkah: tulis satu perilaku per butir; baca ulang; jangan mengubah `src/` di tiket ini.
- Cara membuktikan: setiap butir adalah aturan. DATA-23 / BE-29 / FE-32 / AN-37 dapat dijalankan tanpa menebak kolom, peran, atau angka korban.
- Risiko: menimpa `/analisis-data` resmi G20–G24; membuka `/api/admin/database` ke chart; SQL bebas; median/RPC baru; memperlebar `is_staff` / `is_ops`; tabel admin + PII di gelombang 1; ID menabrak FE-27/FE-28/AN-29.

## Bacaan ulang niat

Ini naskah permukaan + kontrak API/skema, bukan UI pixel. Gelombang 1 = adapter ke GET yang sudah ada. `/analisis-data` resmi tetap. Builder di konsol. Publik hanya slug terbit, kueri per `chart_id` tersimpan. DIBI laci. IRBI/KRB boleh satu kanvas dengan kejadian, tetapi tidak boleh menjadi KPI jiwa.

## Naskah

### 1. Objek

**Perilaku.** Insight = judul + deskripsi + `locale` + `visibility` + `layout` + daftar chart. Chart = satu `source_id` + `chart_type` + `encoding` + `filters` + `layout_item` + judul + caption. Satu chart tidak berbagi kueri diam-diam dengan chart lain.

**Visibility.** `draft` | `staff` | `public`. Baru dibuat = `draft`.

**Locale insight.** `id` atau `en` (default `id`). Judul/deskripsi satu string tersimpan. Chrome i18n halaman memakai `messages`. Rute EN tidak wajib judul terjemahan.

**Slug.** kebab-case dari judul, unik di seluruh baris. Tabrakan → akhiran `-2`, `-3`, …

### 2. Sumber gelombang 1

**Perilaku.** Hanya empat `source_id`. Bukan tabel `ADMIN_TABLES`. Bukan `payload` JSON. Bukan tilikan. Bukan pengungsian. Bukan Tatonas.

| `source_id` | Adapter | publishable | pii |
| --- | --- | --- | --- |
| `kejadian.analisis` | `GET /api/kejadian/analisis` + `buildKejadianAnalisis` | true | false |
| `irbi.kab` | `GET /api/irbi` | true | false |
| `krb.kab` | `GET /api/krb` | true | false |
| `dibi.aceh` | `GET /api/dibi/aceh` | true | false |

**Grain.** Pemetaan ke keluaran yang sudah ada, bukan GROUP BY baru.

- `kejadian.analisis` dimensi: `jenis` | `kabupaten` | `bulan` | `tahun`. Measure: `kejadian` | `rumah` | `korban` (`AnalisisMetric` yang ada). KPI memakai `total` atau field `impact` yang sudah dihitung (`rr`, `rs`, `rb`, `luka` = ringan+berat, `meninggal` = meninggal+hilang katalog).
- `irbi.kab` dimensi: `kabupaten` | `ancaman` (`KRB_JENIS_KODE`). Measure tampilan: `skor` (angka) atau `kelas` (RENDAH/SEDANG/TINGGI). `kelas` tidak di-`sum`.
- `krb.kab` dimensi: `kabupaten` | `ancaman`. Measure: `kelas` terbit. Bukan zona I/II/III.
- `dibi.aceh` dimensi: yang sudah ada di payload DIBI (jenis / kab tanpa jenis / tahun). Jangan filter kab×jenis. Caption wajib memuat kata DIBI.

**Sumber selain tabel di atas.** 400. Jangan menambah adapter diam-diam.

### 3. Jenis chart gelombang 1

**Perilaku.** Tujuh jenis: `kpi` | `bar` | `line` | `area` | `pie` | `table` | `map`.

| Jenis | Sumber yang sah |
| --- | --- |
| `kpi` | hanya `kejadian.analisis` |
| `bar` `line` `area` `pie` `table` | keempat sumber; IRBI/KRB tidak memakai measure jiwa |
| `map` | hanya `kejadian.analisis` + dimensi `kabupaten` + `AnalisisKabMap` |

Jenis lain = 400. Batang bertumpuk = `bar` + `series` opsional pada `jenis` kejadian; bukan jenis ke-8.

### 4. Encoding dan filter

**Perilaku.** `encoding` = `{ dimension, measure, series? }`. Field harus ada di registri sumber itu. Selain itu = 400.

**Agregasi.** Tidak ada `median` / `min` / `max` / RPC baru. Angka = field keluaran adapter yang sudah teragregasi.

**Filter gelombang 1.** Hanya kunci yang sudah hidup di analisis publik: `jenis`, `kabupaten`, `kecamatan`, `from`, `to`, `metric`, `ancaman`. Operator hanya kesetaraan nilai atau rentang tanggal yang sama dengan `analisisSearch`. Tidak ada `like`. `ancaman` hanya kode `KRB_JENIS_KODE`.

**Kuota.** Maksimum 12 chart per insight. Deret adapter maksimum mengikuti payload analisis yang ada (bukan unduh seluruh tabel). `layout`: kisi 12 kolom; `w` 2–12; `h` 2–8; `y+h` ≤ 24.

### 5. Mesin kueri

**Perilaku.** Bukan SQL pengguna. Bukan `/api/admin/database`. Bukan GROUP BY generik di Node atas seluruh tabel.

**Pratinjau staf.** `POST /api/insight/query` body `{ source_id, encoding, filters }`. Wajib sesi + `requireModuleApi("insight")` + `rejectCrossOrigin`. Validasi zod terhadap registri. `admin_kabkota`: `filters.kabupaten` dipaksa ke `scopeKabupaten`; tanpa kode kab = 403 (AN-20). Sumber `pii` tidak ada di G1.

**Baca publik.** `GET /api/insight/public/[slug]`. Klien **tidak** mengirim `source_id` / `encoding`. Server memakai chart tersimpan. Slug bukan `public` → 404 (bukan 403).

**Kosong vs hulu.** Chart: `{ status: "ok" | "empty" | "upstream", series, stamp }`. Insight publik HTTP 200 jika slug terbit. Satu chart `upstream` tidak membuat seluruh insight 503. `POST /api/insight/query` untuk satu sumber mati = 503 `{ error: "upstream" }`. Kosong sah = 200 + `status: "empty"`.

**Stempel.** Setiap chart menampilkan `source_id` + cap sumber adapter (sama semangat `/sumber-data`).

### 6. Isolasi angka

**Perilaku.** Insight boleh memuat chart `kejadian.analisis` dan `irbi.kab` / `krb.kab` bersamaan. Chart IRBI/KRB wajib caption bahwa itu kelas/skor terbit, bukan prediksi dan bukan jiwa. `chart_type=kpi` dilarang untuk `irbi.*` / `krb.*` / `dibi.*`. Skor IRBI/KRB dan angka DIBI tidak masuk measure `kpi` kejadian. Join IRBI/KRB gagal = `empty`, bukan kelas karangan. DIBI tidak menjadi riwayat kab×jenis (AN-32).

### 7. Peran

**Perilaku.** Modul baru `insight` di `SikModule`. Jangan mengubah isi `is_staff()` / `is_ops()`. Jangan membuka modul `database`.

| Tindakan | Siapa |
| --- | --- |
| Buat / ubah / hapus / terbit / unpublish | `super_admin` atau `admin_provinsi` (`isProvinsiOps`) |
| Lihat daftar + detail `draft`/`staff` + pratinjau query sumber G1 | di atas, plus `admin_kabkota` (filter kab dipaksa) |
| Selain itu | 403 |

Semua `isProvinsiOps` boleh menyunting insight mana pun (bukan kunci pemilik di G1). `admin_desa`, `penilai_pkd`, `admin_rr` tidak masuk modul.

### 8. Skema dan RLS

**Perilaku.** Migrasi **baru** (DATA-23). Jangan menyunting migrasi lama.

Tabel `insight`: `id` uuid pk, `slug` unique text, `title` text, `description` text, `locale` text check (`id`,`en`), `visibility` text check (`draft`,`staff`,`public`), `layout` jsonb, `created_by` uuid null, `created_at`, `updated_at`, `published_at` timestamptz null.

Tabel `insight_chart`: `id` uuid pk, `insight_id` fk cascade, `source_id` text, `chart_type` text, `title` text, `caption` text, `encoding` jsonb, `filters` jsonb, `layout_item` jsonb, `sort_index` int.

**RLS.** ENABLE pada kedua tabel. Tanpa kebijakan `ALL`. Anon: tanpa GRANT SELECT/INSERT/UPDATE/DELETE. `authenticated` SELECT = `is_staff()`. INSERT/UPDATE/DELETE = `is_ops()`. Route handler publik memakai service role **hanya** untuk membaca baris `visibility=public`; jangan memakai service role untuk pratinjau staf. Jangan expose tabel ke Data API anon.

### 9. Terbit dan hapus

**Perilaku.** Terbit (`visibility=public`) ditolak jika ada chart `source_id` di luar registri G1 atau `chart_type` tidak sah atau caption IRBI/KRB/DIBI kosong. G1 semua sumber `publishable=true`, jadi PII tidak masuk. Setelah terbit, query publik mengabaikan encoding klien. Ubah encoding chart terbit = ops segera memakai encoding baru (tanpa snapshot). Unpublish = `visibility=staff`, `published_at` tetap sebagai jejak, GET publik 404. Hapus = cascade chart, hanya `isProvinsiOps`.

### 10. Rute dan inventaris

**Perilaku.** `/analisis-data` dan `/en/disaster-analysis` resmi **tidak diubah** (G20–G24 tetap).

Staf: `/admin/insight`, `/admin/insight/[id]` (locale id/en).  
Publik terbit: `/analisis-data/[slug]`, `/en/disaster-analysis/[slug]`.

API:

| Metode | Path | Siapa |
| --- | --- | --- |
| GET | `/api/insight/sources` | modul insight |
| GET POST | `/api/insight` | GET: modul; POST: `isProvinsiOps` |
| GET PATCH DELETE | `/api/insight/[id]` | GET: modul; tulis: `isProvinsiOps` |
| POST | `/api/insight/[id]/charts` | `isProvinsiOps` |
| PATCH DELETE | `/api/insight/[id]/charts/[chartId]` | `isProvinsiOps` |
| PATCH | `/api/insight/[id]/layout` | `isProvinsiOps` |
| POST | `/api/insight/[id]/publish` | `isProvinsiOps` |
| POST | `/api/insight/query` | modul insight |
| GET | `/api/insight/public/[slug]` | anon |

**Inventaris.** BE-29 menambah path di atas ke `security/attack-surface.md` dan tes inventaris. `GET /api/insight/public/[slug]` tidak boleh memuat PII / `jawaban_json` / identitas pelapor.

**Batas.** `POST /api/insight/query` menolak origin silang. Tanpa `guardPublicPost` (itu POST warga). Pratinjau staf: maksimum 30 permintaan / menit / sesi; lebih = 429.

### 11. Layout dan pustaka

**Perilaku.** Mode “sunting chart” terpisah dari mode “tata letak”. Layout tersimpan di `insight.layout` (bukan hanya `localStorage`).

**Pustaka.** Chart = `recharts` yang sudah ada. Grid = `react-grid-layout` **mayor 2.x** (API v2 / hooks; jangan contoh v1 kecuali import `react-grid-layout/legacy`). Komponen grid `dynamic(..., { ssr: false })`. Jangan Hex/Looker/Superset. Jangan grid kustom.

### 12. Alur UI

**Perilaku.**

1. Staf `isProvinsiOps` mengisi judul + deskripsi → `POST /api/insight` → kanvas kosong `draft`.
2. Tambah chart: pilih `source_id` → jenis → encoding/filter → pratinjau `POST /api/insight/query` → simpan chart.
3. Tata letak: geser/ubah ukuran → `PATCH .../layout`.
4. Terbit opsional → slug publik baca saja.

Tidak ada langkah “jenis dulu, sumber belakangan”.

### 13. Kasus emas

**Perilaku.**

1. Insight “Banjir Pidie Jaya”: chart `bar` `kejadian.analisis` `dimension=kabupaten` `measure=kejadian` `filters.kabupaten=Pidie Jaya`; chart `bar` atau `table` `irbi.kab` `ancaman=banjir` berkaption. KPI kejadian (jika ada) ≠ 26,4.
2. `chart_type=kpi` + `source_id=irbi.kab` → 400.
3. `POST /api/insight/query` dengan `source_id=admin.kejadian_bencana` → 400.
4. `GET /api/insight/public/slug-draft` untuk insight `draft` → 404.
5. Anon `POST /api/insight/query` → 401/403.
6. Publik mengirim `encoding` di query string diabaikan; angka = encoding tersimpan.
7. `admin_kabkota` tanpa `kodeKabupaten` → 403 pada query.
8. Hulu `kejadian.analisis` mati pada pratinjau → 503; pada halaman publik terbit → chart `upstream`, insight 200.
9. Pidie Jaya × `ancaman=gempabumi` pada chart IRBI: kelas TINGGI 26,4 jika join berhasil (AN-32); chart kejadian gempa boleh `empty`.
10. Setelah unpublish, slug publik 404. Setelah reload editor, `layout` sama.

### 14. Non-tujuan

**Perilaku.** Jangan SQL bebas. Jangan unggah CSV. Jangan tabel admin / laporan / tilikan / pengungsian di G1. Jangan median/RPC agregasi baru. Jangan PAGER/OpenQuake. Jangan meninggal dari skor IRBI. Jangan zona KRB I/II/III. Jangan query DIBI kab×jenis baru. Jangan menimpa panel G20–G24 di `/analisis-data`. Jangan mengubah `IrbiHeroPanel` / `KrbHeroPanel`. Jangan memperlebar `is_staff` / `is_ops`. Jangan membuka P2 Juklak. Jangan DATA-4. Jangan POST nasional. Jangan apply migrasi dari tiket naskah ini.

### 15. Tiket pelaksana (setelah naskah ini)

**Perilaku.** Jangan dikode sebelum jurnal ini `selesai`. Urutan: DATA-23 (migrasi) → BE-29 (API + inventaris) → FE-32 (UI) → AN-37 (uji). FE-32 boleh memulai tes RED kontrak encoding sebelum BE hijau, tetapi tidak merender data hidup tanpa adapter.
