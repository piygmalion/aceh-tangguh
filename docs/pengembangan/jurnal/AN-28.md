# AN-28 — naskah 200 vs 503

Agent: analis
Gelombang: ECC-S3
Status: siap-kode

## Niat

Mengunci kapan overlay/cuaca menjawab 200 kosong sah vs 503 hulu. Jangan menggabungkan cuaca resmi dan inovasi.

## Bacaan ulang niat

Tulisan. Bukan opsi. Path cron lama tidak dihapus.

## Naskah

### Live overlay (`/api/overlay/{kunci-hidup}`)

Sepi sah = 200 + FeatureCollection kosong tanpa `stale`. Hulu gagal = 503 + `stale` + `error: "upstream"`. Tidak berubah.

### Static + maritime

Catch tetap **200 + `stale: true` + features []**. Alasan: ini jalur fixture/disk + prakiraan tempel. Lempar di sini = gagal baca lokal, bukan ledger hulu. 503 akan membuat toolbar FE-3 menandai layer statis sebagai “sumber gagal” seolah umpan hidup mati. Maritime cache kosong sudah AN-19: fixture + `stale`, bukan 503.

Samakan badan catch: FeatureCollection kosong + `stale: true`. Maritime boleh tetap `source: "bmkg-maritim"`.

### Cuaca

`/api/weather` dan `/api/weather/inovasi` tetap terpisah. Jangan merge handler atau tabel.

### Cron

Alias saja: `POST /api/cron/weather` dan `/api/cron/weather-inovasi` memanggil handler yang sama. Path `/api/weather/refresh` dan `/api/weather/inovasi/refresh` **tetap**. Jangan menulis nilai secret. Dokumentasi di `docs/vercel.md`.

### 404

`GET /api/overlay/{kunci-statis}` = 404 + `hint` path AN-19 (`/api/overlay/static/…` atau `/api/overlay/maritime/perairan`).
