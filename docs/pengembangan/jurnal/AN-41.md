# AN-41 — naskah User Management katalog

Agent: analis
Gelombang: 33
Status: selesai

Tulisan. Bukan kode pada tiket ini. ID AN-38 / AN-39 / DATA-24 / BE-29 / FE-39 sudah Daily Brief (G31). Jangan menimpa jurnal itu. Jangan memakai AN-40 / DATA-25 / BE-30 / FE-40 (G32 riset AI). Kontrak ini untuk DATA-26 / BE-31 / FE-41 / AN-42.

## Niat

- Tujuan: Mengunci dashboard Super Admin untuk membentuk, menangguhkan, menghapus semua staf, menugaskan peran katalog, dan mengubah paket akses modul — tanpa nama peran bebas dan tanpa merevoke helper SQL.
- Berkas: jurnal ini. Koordinator menambah baris STATUS / gelombang / brief. Tiket ini tidak menyunting `src/` atau migrasi.
- Langkah: satu aturan per butir; baca ulang; jangan menebak email, nama desa, atau `loggerKind`.
- Cara membuktikan: DATA/BE/FE dapat dijalankan tanpa menebak aktor, undangan, 409 terakhir, atau batas RLS.
- Risiko: menimpa AN-38 Daily Brief; membaca AN-22 sebagai larangan PATCH; merevoke `is_staff` / `is_ops` / `is_walidata`; membuka RBAC dinamis.

## Bacaan ulang niat

Katalog tetap: tujuh nilai `AdminRole`. Paket akses hanya `canAccessModule` (nav + `requireModuleApi`). RLS `is_staff` / `is_ops` / `is_super_admin` / `is_walidata` tidak berubah. AN-22 §4/§6 menunda PATCH nonaktif dan undangan non-kab **untuk G18**; naskah ini **membuka** itu. Pelapor tanpa `admin_profiles` tetap `/admin/denied`.

## Naskah

### 1. Aktor

**Perilaku.** Hanya `super_admin`: `requireSuperAdminApi` pada semua metode `/api/admin/users` dan `/api/admin/roles`; `requireSuperAdminPage` pada `/admin/staf`. `admin_kabkota` / `admin_provinsi` / peran lain → API 403, halaman redirect ke `/admin/moderasi`. Mutasi: `rejectCrossOrigin`. Service role hanya di server. Jangan password di body. Jangan seed email.

### 2. Daftar

**Perilaku.** `GET /api/admin/users` mengembalikan `{ users, slots }`.

- `users`: semua baris `admin_profiles` (bukan hanya kab) + `email` + `banned_until` dari Auth Admin `listUsers`. Status `active` jika tidak tertangguh; `suspended` jika `banned_until` di masa depan.
- `slots`: 23 baris katalog `ACEH_KABUPATEN` seperti G18 (terisi/kosong, email jika ada). Kompatibel FE-34.

Jangan mengarang email. Jangan memakai explorer `/admin/database` untuk kelola user (`admin_profiles` tetap di luar `ADMIN_TABLES`).

### 3. Undang

**Perilaku.** `POST /api/admin/users` memakai `inviteUserByEmail`. Tanpa password. `role` wajib dari katalog (`SIK_ROLES`). `admin` diterima dan dinormalisasi ke `admin_provinsi` pada profil.

| Peran | Wilayah |
| --- | --- |
| `admin_kabkota` | Wajib `findKabupaten`. Tulis kode + nama katalog. Duplikat slot → 409 `kabupaten_occupied`. |
| `admin_desa` | Wajib `parseKodeDesaAceh` (10 digit, awalan `11`). Harus ada baris `profil_desa.kode_desa_kelurahan`. Nama desa/kab/kec **disalin dari registri**, jangan dikarang. Tidak ada → 400 `desa_not_found`. |
| peran lain | Kolom wilayah null. |

Insert profil gagal → `deleteUser` rollback (sama G18). Email kosong / tanpa `@` → 400 `email_required`. Peran di luar katalog → 400 `role_required`.

`authorizeStaffInvite` kab tetap dipakai untuk jalur kab. Helper baru boleh membungkus peran lain; jangan membuang fungsi kab.

### 4. Ubah

**Perilaku.** `PATCH /api/admin/users/[id]`. Field: `displayName`, `role`, wilayah, `suspended` (boolean).

- Ganti meninggalkan `admin_kabkota` mengosongkan `kode_kabupaten` / `kabupaten` (slot bebas). Masuk `admin_kabkota` mengikuti §3 (katalog + unik).
- Masuk `admin_desa` mengikuti §3 (kode + registri).
- Tidak boleh mengubah peran **diri sendiri** menjauh dari `super_admin` → 409 `self`.
- Tidak boleh menurunkan **super_admin terakhir** → 409 `last_super_admin`.
- Target tidak ada → 404.

### 5. Tangguh / pulihkan

**Perilaku.** `suspended: true` → `auth.admin.updateUserById` dengan `ban_duration` yang membuat `banned_until` di masa depan (mis. `876000h`). `suspended: false` → `ban_duration: "none"`. Bukan kolom `suspended` di `admin_profiles`.

Tidak boleh menangguhkan diri sendiri → 409 `self`. Tidak boleh menangguhkan super_admin terakhir → 409 `last_super_admin`. Pengguna tertangguh tidak lolos sesi konsol (`getUser` / Auth menolak).

### 6. Hapus

**Perilaku.** `DELETE /api/admin/users/[id]`. `auth.admin.deleteUser` (profil cascade `ON DELETE CASCADE`). 409 `self` jika target = aktor. 409 `last_super_admin` jika target adalah satu-satunya `super_admin`. 404 jika tidak ada.

### 7. Paket akses

**Perilaku.** Tabel baru `admin_role_modules (role, module, allowed)`. PK `(role, module)`. Role = nilai katalog. Module = kunci `SikModule` termasuk `dailyBrief`. Seed = matriks `canAccessModule` hari ini (`super_admin` semua true; `cms`/`database` false kecuali `super_admin`; `dailyBrief` = `admin_provinsi` + `super_admin`).

- `GET /api/admin/roles` → matriks lengkap.
- `PATCH /api/admin/roles` → ubah `allowed` per `(role, module)`. Baris `role = super_admin` **ditolak** (400 `super_locked`).
- `canAccessModule`: jika overlay baris ada untuk peran ternormalisasi, pakai `allowed`; jika tabel belum ada / baca gagal, fallback switch hardcoded hari ini. `super_admin` tetap selalu true (tidak bisa dikunci overlay).
- Overlay **tidak** mengubah RLS. Memberi `cms`/`database` ke peran lain boleh menampilkan nav; tulis Postgres tetap `is_super_admin()`.
- RLS tabel: SELECT `is_super_admin()`; tulis `service_role`.
- Jangan merevoke `is_staff` / `is_ops` / `is_super_admin` / `is_walidata`.

### 8. Permukaan

**Perilaku.** Tetap `/admin/staf` (jangan rute `/admin/pengguna`). Dua panel: daftar pengguna (undang + ubah + tangguh + hapus dengan konfirmasi) dan kisi peran × modul. Ringkasan 23 slot tetap ada (komponen G18/FE-34 jangan dihapus). Nav label boleh “Pengguna” / “Users”; href `/admin/staf`. i18n `admin.*` ID+EN. Kunci `staffPending` / `staffActive` boleh dipakai ulang; jangan sinonim status baru kecuali `staffSuspended`.

### 9. Non-tujuan

**Perilaku.** Bukan Casbin / nama peran bebas. Bukan pelapor publik. Bukan sunting user lewat `/admin/database`. Bukan AN-36 / AN-37 / FE-38. Bukan G31 Daily Brief. Bukan G32 AI. Bukan DATA-4. Bukan POST nasional. Bukan P2 Juklak.
