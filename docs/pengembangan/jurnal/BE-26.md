# BE-26 — rencana pensiun /admin/reports

Agent: backend
Gelombang: ECC-S4
Status: selesai

## Niat

Jurnal rencana saja. Jangan DROP `reports`. Jangan hapus baris warisan.

## Rencana operator

1. Provinsi/`super_admin` masih melihat `/admin/reports` untuk baris lama.
2. Kab sudah 403 (AN-22 / BE-18).
3. Pensiun UI setelah hitung baris `reports` yang belum ada padanan `laporan_*` dan operator menyalin atau menutup.
4. `/api/reports` tetap 410. Tabel tetap.
5. Tiket kode kemudian: sembunyikan nav setelah operator menulis “nol baris aktif”. Bukan tiket ini.
