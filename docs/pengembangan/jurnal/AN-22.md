# AN-22 — naskah moderasi scoped + undangan 23 kab

Agent: analis

Status: selesai

## Niat

- Tujuan: Mengunci aturan moderasi per kabupaten dan administrasi undangan tanpa peran enum baru, sebelum BE-18/BE-19/FE-18.
- Berkas: jurnal ini. Kode di tiket berikutnya.
- Tidak diubah di tiket ini: `parse.ts`, DATA-4, `is_staff`, `is_ops`.
- Operator: 23 email resmi ditempel di UI setelah FE-18. Jangan mengarang email.

## Bacaan ulang niat

Satu perilaku per butir. Kolom laporan adalah `kabupaten_kota`, bukan `kode_kabupaten`. Reports warisan tidak punya kolom kab.

## Naskah

### 1. Peran

Tidak menambah `admin_moderasi`. `admin` tetap alias `admin_provinsi`. Moderasi = modul. Administrasi akun = `super_admin` saja.

### 2. Moderasi `laporan_*`

Helper baru (`authorizeLaporanList` / `matchesLaporanKabScope`), bukan `matchesKabScope` mentah.

- Bukan `admin_kabkota` → tidak tersaring.
- `admin_kabkota` tanpa `kode_kabupaten` dan tanpa `kabupaten` → 403.
- Scope harus lolos `findKabupaten`. Jika tidak → 403.
- Baris lolos hanya jika `findKabupaten(kabupaten_kota)` menghasilkan kode yang sama dengan scope.
- `GET` list dan `summary=1` memakai filter `kabupaten_kota.eq.kode` ATAU `kabupaten_kota.eq.nama` katalog.
- `PATCH`: muat baris dulu; kab asing atau `kabupaten_kota` yang tidak lolos katalog → 403. Baru kemudian `update`.

### 3. Reports warisan

`GET`/`PATCH` `/api/admin/reports`: `admin_kabkota` → 403. Jangan mengurai `place_name`. Provinsi/`super_admin` tetap. UI menyembunyikan tab formulir lama untuk kab.

### 4. Administrasi

Hanya `super_admin`. Gelombang ini `POST` hanya `admin_kabkota`.

- Email wajib, bukan string kosong. Tidak ada password di API.
- Kabupaten wajib dari `ACEH_KABUPATEN` (`findKabupaten`). Tulis `kode_kabupaten` dan `kabupaten` katalog.
- Satu `admin_kabkota` aktif per kode 4 digit. Duplikat → 409.
- `GET` mengembalikan 23 slot katalog (terisi/kosong). Jangan seed email.
- `PATCH` nonaktif tunda (bukan gelombang ini).

### 5. DATA-12

Unik parsial `admin_profiles (kode_kabupaten) where role = 'admin_kabkota' and kode_kabupaten is not null`. Migrasi baru. Jangan apply dari tiket kode. Jangan revoke fungsi peran.

### 6. Non-tujuan

Desa / penilai / `admin_rr`. Peran baru. DATA-4. POST nasional.
