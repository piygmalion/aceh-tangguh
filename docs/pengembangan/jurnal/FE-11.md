Agent: frontend

## Niat

- Tujuan: Tiga permukaan staf yang KOORD-G6 masih catat sebagai sisa i18n, tanpa meni18n-kan seluruh halaman detail. (1) Header kolom `KIB` di daftar kejadian lewat `admin.colKib`. (2) Status baris daftar memakai kunci `admin` yang sudah ada, bukan CSS `.capitalize` pada nilai mentah. (3) Tanggal di daftar calon dan di header detail memakai locale next-intl, bukan `toLocaleString("id-ID")`. Suffix ambang di detail lewat kunci baru `admin.labelBelowThreshold`.
- Berkas (hanya ini):
  - `src/components/sik/KejadianOpsList.tsx` — header KIB + peta status sel
  - `src/components/sik/CalonKejadianList.tsx` — HANYA baris tanggal + impor `useLocale`
  - `src/components/sik/KejadianOpsDetail.tsx` — tanggal + dua suffix; impor next-intl
  - `messages/id.json`, `messages/en.json` — HANYA kunci baru `admin.colKib` dan `admin.labelBelowThreshold`
  - `docs/pengembangan/jurnal/FE-11.md`
  - `docs/pengembangan/STATUS.md` — HANYA baris FE-11
- Tidak diubah:
  - Fetch, banner SDB, tautan calon/SDB/baru, form terima/tolak calon
  - Namespace `sikCalon` (AN-6 terkunci — jangan menambah kunci)
  - Kunci `admin` yang sudah ada (`statusDraft`, `statusAktif`, `statusSelesai`, `statusDiarsipkan`, `labelIsBencana`, dan sisanya)
  - Tombol fase / cetak / string error hardcoded di detail ("Ajukan verifikasi", "Kunci data statis", "Buka kunci", "Cetak Lampiran I", dan error)
  - `fase_data` di sel status — tetap data mentah
  - Destana, DATA-4, item sidebar. Tidak commit. Tidak meni18n-kan seluruh halaman detail.
- Langkah:
  1. Tambah dua kunci baru di `admin` (id + en), tanpa menimpa kunci lama:
     - `colKib` — id: `KIB`; en: `KIB` (akronim sama)
     - `labelBelowThreshold` — id: ` · di bawah ambang`; en: ` · below threshold` (suffix penuh termasuk pemisah, sama pola `labelIsBencana`)
  2. `KejadianOpsList.tsx`: header `<th>` `KIB` → `{t("colKib")}`. Sel status: peta `draft`/`aktif`/`selesai`/`diarsipkan` → `t("statusDraft"|"statusAktif"|"statusSelesai"|"statusDiarsipkan")`. Nilai lain tampil apa adanya (data). Hapus `className="capitalize"` pada sel itu. `fase_data` tetap mentah. Tanggal baris sudah `useLocale()` dari FE-10 — jangan diubah lagi. Jangan mengubah fetch, banner, tautan.
  3. `CalonKejadianList.tsx`: impor `useLocale` dari next-intl. Baris `waktu_sinyal`: jika string, `new Date(…).toLocaleString(locale)`; jika kosong, placeholder `"—"` tetap. Jangan menambah kunci `sikCalon`. Jangan mengubah form terima/tolak.
  4. `KejadianOpsDetail.tsx`: impor `useTranslations("admin")` + `useLocale()`. Tanggal fallback: `new Date(item.waktu_kejadian).toLocaleString(locale)` (jika `item.tarikh` ada, tetap pakai `tarikh` — itu data, bukan locale format). Suffix: `item.is_bencana ? t("labelIsBencana") : t("labelBelowThreshold")`. Jangan menerjemahkan tombol fase, cetak, atau error.

  - Menambah kunci `sikCalon` — dicegah: tanggal calon memakai `useLocale()`, bukan kunci baru.
