# FE-60 — raster GIBS + titik FIRMS di peta

Agent: frontend
Gelombang: 37
Status: selesai

ID awal draf adalah FE-57. Setelah rebase ke `main` (tip memuat #106), FE-57 sudah dipakai Tanggapi jalur analisis data. Tiket peta G37 dinomori ulang menjadi FE-60. `docs/pengembangan/jurnal/FE-57.md` analisis tidak ditimpa.

## Niat

- Tujuan: Menampilkan allowlist GIBS/FIRMS di `/peta` lewat `?nasa=` dan `?nasaDate=`.
- Berkas: URL state, toolbar, viewport, `NasaNrtOverlays.tsx`, i18n `map.*`, `map-url-sync` (#103).
- Langkah: parser terpisah dari overlays; kelompok konteks satelit; kartu FIRMS; hint awan; tulis query lewat `history.replaceState`, bukan `router.replace`.
- Cara membuktikan: uji isolasi i18n; `map-url-sync.test.ts`; `tsc`; browser jika sesi menjangkau dev server.
- Risiko: token nasa di overlays; ukuran marker resmi berubah; menulis kamera/nasa dengan App Router sehingga nav keluar `/peta` memantul.

## Bacaan ulang niat

Default nasa mati. Titik FIRMS memakai `MAP_DOT_RADIUS_PX` yang sama, tanpa mengubah konstanta marker. Persistensi URL tetap pola #103: `createMapUrlWriter` membatalkan tulis tertunda saat klik SiteNav meninggalkan peta.
