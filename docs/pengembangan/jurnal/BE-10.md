  1. `evaluateKunciStatis` murni, tanpa jaringan. Butir (satu perilaku masing-masing):

     3. `findKabupaten(kode_kabupaten)` **atau** (`kib_sumber` ∈ {`episentrum`,`laut`} dan `findKabupaten(kode_kabupaten_kib)`).
     4. Jika `kib_sumber = lokasi`: `kode_kecamatan` `/^\d{6}$/` dan `startsWith` kode kabupaten (kode hasil `findKabupaten` jika ada); `kode_desa_kelurahan` `/^\d{10}$/` dan `startsWith` kode kecamatan.
     5. Jika `kib_sumber` ∈ {`episentrum`,`laut`}: langkah 4 tidak dijalankan; `kib_catatan` trim nonempty wajib.
     6. `latitude` dan `longitude` tidak null; hitung digit di belakang koma dari representasi tersimpan (`String(n)`; `toFixed` hanya untuk hitung jika finite / notasi ilmiah). Jangan mengisi/mengarang desimal. Digit < 6 → gagal.
     7. `kib` lolos `/^\d{16}$/`; jika tidak, gagal.
     8. Jangan membaca / mensyaratkan korban, `nomor_sk`, atau KRB.
     Kumpulkan semua error; jangan short-circuit.
  2. `POST .../fase` ke `statis`: tetap `rejectCrossOrigin` + `requireOpsApi` + `canLockStatis` + `matchesKabScope`. Jangan gagal hanya karena catatan body kosong. Cabang `statis` → `dinamis` tidak menulis validasi. Insert gagal setelah update → 500 (kebijakan yang sama).
  5. GET `/api/sik/kejadian/peringatan-dinamis` — `requireOpsApi`. Filter `status_darurat = true` AND `fase_data = dinamis` AND `lacksDampakPadaTanggal` untuk hari ini `Asia/Jakarta` (`todayJakartaYmd`). Scope: `matchesKabScope` (kabkota terbatas; provinsi / `super_admin` semua). Body `{ count, items: [{ id, nama_kejadian, kabupaten, kode_kabupaten }] }`. Jangan `notifikasi_wa` / WhatsApp.
  6. `fase_data = dinamis` / PATCH kejadian: jangan menambah checklist.
