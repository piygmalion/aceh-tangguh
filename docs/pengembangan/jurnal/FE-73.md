# FE-73 — lembar bawah peta

Agent: frontend
Gelombang: visual
Status: diverifikasi

## Niat

- Tujuan: Di bawah 768, keterangan fitur menjadi lembar bawah yang bisa digeser (mengintip, setengah, penuh) dan menghormati safe-area. Popup yang mengambang di desktop dijepit ulang saat peta bergerak, paling jauh 8px dari tepi. Kotak ⓘ dan tombol "+" tidak bertumpuk di 390. Chip legenda status minimal 44px. Daftar kab/kota menyisakan ruang di bawah baris terakhir. Kueri keterangan terikat pada id fitur dan batal bila id berganti.
- Berkas: `MapViewport.tsx`, `MapFeatureCard.tsx`, `MapFeatureSheet.tsx`, `ReportFAB.tsx`, `StatusScaleChip.tsx`, `DataHero.tsx`, `src/lib/map-sheet.ts`, `src/lib/feature-card-query.ts`, `messages/id.json`, `messages/en.json`, uji, jurnal.
- Langkah: Lembar menggantikan popup MapLibre hanya di bawah 768. `onMove` memanggil penjepit yang sudah ada. FAB naik setinggi strip kredit ditambah 8px. Chip `min-h-[44px]`. Daftar "Kejadian per kab/kota" mendapat `pb-6`. `queryFn` memakai id pada kunci dan `AbortSignal`.
- Cara membuktikan: `npx tsc --noEmit`, `npm test`, `npm run lint`, `npm run build`. Tangkapan 390 dan 1440.
- Risiko: Lembar menutup pegangan panel. Desktop kehilangan popup mengambang. Angka korban dikarang.

## Bacaan ulang niat

Tidak ada spec lembar di repositori. Asumsi: tiga henti (mengintip 120px, setengah ruang yang tersisa, penuh sampai di bawah header 6rem); lembar duduk di atas pegangan panel (`4.25rem` + safe-area) supaya pegangan tetap bisa diketuk; desktop tetap popup mengambang. Daftar kab/kota yang dimaksud adalah "Kejadian per kab/kota" di beranda. Tidak mengubah palet, font, nama "SIK Aceh", atau kredit "dokumentasi Aceh Tangguh". Tidak mengarang data.
