# AN-44 — naskah berkas percakapan Tanggapi (lokal)

Agent: analis
Gelombang: Tanggapi berkas percakapan
Status: selesai

Tulisan. Bukan kode pada tiket ini. ID AN-38 / FE-39 sudah Daily Brief (G31) — jangan menimpa jurnal itu. Jangan menimpa AN-37, FE-38, AN-36, AN-4, FE-16, atau FE-17 (hook peta). FE-49 mengimplementasikan naskah ini.

## Niat

- Tujuan: Mengunci satu perilaku supaya Tanggapi menyimpan **berkas percakapan di perangkat** (`sessionStorage`) dan menampilkan briefing sebagai **kartu empat umpan**, tanpa menjadi CRM staf, pipeline penjualan, atau basis data kontak warga.
- Berkas: jurnal ini. FE-49 yang menyunting `src/` setelah naskah `siap-kode`.
- Langkah: tulis aturan tunggal per butir; baca ulang; jangan menebak `loggerKind` Tatonas, zona KRB, atau angka korban.
- Cara membuktikan: setiap butir adalah aturan, bukan opsi. Frontend dapat hydrate/persist/hapus thread dan merender klausul briefing tanpa menebak pemicu, sanitasi, atau tautan.
- Risiko: fetch umpan saat FAB tertutup; POST kontak; menyimpan nomor HP/isi laporan; dorong briefing kedua di atas thread yang sudah ada; menaikkan kuota Grok; menimpa jurnal G31.

## Bacaan ulang niat

Rekaman CRM di sini adalah **sesi tab peramban**, bukan warga. Pola yang dipinjam dari CRM staf generik: thread + rel konteks + parse di batas. Yang tidak dipinjam: deal, company, inbox, tracking script, Nest/tRPC. Briefing AN-37 tetap sumber isi peringatan. FE-38 tetap compiler.

## Naskah

### 1. Pemicu memori

**Perilaku.** Pulihkan thread hanya ketika panel dibuka (sama jendela `handleOpen`). Jangan `GET /api/peringatan-dini` atau umpan lain saat FAB tertutup. Jangan `setInterval` / service worker / Web Push.

Jika thread tersimpan punya satu pesan atau lebih: tampilkan thread itu dan **jangan** memanggil `pushWelcome` (jangan briefing kedua).

Jika thread kosong atau storage gagal/ditolak: perilaku sambutan seperti FE-38 / AN-37 (`welcomeQueryForPath`). Halaman Destana, nomor penting, dan halaman lain tidak diganti.

### 2. Isi yang boleh tersimpan

**Perilaku.** Satu objek versi `1` di `sessionStorage` (kunci milik Tanggapi, bukan seed FE-37). Isi: `messages` dan `slots` (`kabupaten`, `jenis`, `year`, `lastIntent`). Setiap pesan: `id`, `role` (`user` | `bot`), `body`, `intent` opsional, `links` opsional (hanya `GuideHref` yang sudah ada + hash string pendek), `clauses` opsional (maksimal empat string untuk kartu peringatan), `source` opsional.

Cap: 40 pesan; jika lebih, buang yang tertua. JSON rusak, versi asing, atau field bukan tipe: anggap kosong, jangan crash.

Sanitasi di batas tulis:

- Pesan `user`: `sanitizeUnknownQuery` (email, tel, angka panjang, cap 160).
- Pesan `bot`: hapus pola email dan nomor tel yang sama; **jangan** memotong angka umpan resmi (muka air, magnitudo) dengan filter `\d{8,}`.
- Jangan menyimpan nama lengkap, isi formulir laporan, atau nomor HP utuh.

Jangan persist objek FAQ mentah, konteks API, atau jawaban Grok internal (`sourceId`).

### 3. Bukan CRM staf

**Perilaku.** Tidak ada POST kontak, tidak ada tabel percakapan di server, tidak ada inbox admin, tidak ada siaran `notifikasi_wa` ke publik. `logUnknownIntent` yang sudah ada bukan penyimpanan thread.

### 4. Kartu briefing

**Perilaku.** Jika `intent` adalah `peringatan` dan ada `clauses` (urutan cuaca, MAGMA, Sipongi, Tatonas dari `compileAlertBrief`): UI menampilkan lead 112 terpisah plus empat baris. Jika gagal seluruh kunci: satu kalimat tertunda, tanpa empat baris palsu. MAGMA `unavailable` tidak menyalin event lama (AN-37 butir 3). Tautan tetap `#status` / `#cuaca`. Jangan `router.push("/peta")` dari hydrate atau `pushWelcome`.

### 5. Hapus berkas

**Perilaku.** Satu aksi di panel mengosongkan storage thread, mengosongkan `messages` dan `slots` di sesi, lalu menjalankan sambutan halaman yang sama seperti thread kosong. Tidak menghapus `aceh:tanggapi-bubble-seen` atau seed CTA FE-37 kecuali niat FE-37 mengharuskannya (jangan sentuh).

### 6. Grok dan kuota

**Perilaku.** `shouldUseGroundedLlm` untuk intent live `peringatan` tanpa riset tetap `false`. Jangan menaikkan kuota 20/jam. Jangan LangChain. Compiler briefing tetap fungsi murni.

### 7. i18n

**Perilaku.** Kunci baru hanya di namespace `panduan` (rel slot, hapus berkas, label baris kartu jika perlu). Jangan menimpa kunci `open`, `disclaimer`, `chips.*`, atau tautan yang sudah ada. Jangan hero invite baru.

### 8. Non-tujuan

**Perilaku.** Jangan AN-36. Jangan AN-4. Jangan Web Push / SMS. Jangan merge WeatherNext. Jangan DATA-4. Jangan POST nasional. Jangan P2 Juklak. Jangan menyalin Prisma CRM staf. Jangan menimpa `AN-38.md` / `FE-39.md` G31.

## Bacaan ulang naskah

Thread lokal, cap 40, sanitasi user ketat. Thread tidak kosong menahan sambutan. Kartu empat umpan hanya dari compiler yang ada. Bukan inbox staf. ID tiket bukan G31.
