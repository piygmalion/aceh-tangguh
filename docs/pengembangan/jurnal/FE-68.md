# FE-68 — Foto hero beranda

Agent: frontend
Gelombang: kemudian
Status: diverifikasi

## Niat

- Tujuan: Latar hero statistik beranda memakai foto nyata Aceh, bukan stok. Teks putih, batang 19 tahun, dan tombol tetap lolos kontras di atas skrim tinta. Filter dan bagian di bawahnya tidak berubah.
- Berkas: `src/lib/hero-photo.ts`, `src/components/beranda/HeroPhotoBackdrop.tsx`, `DataHero.tsx`, `YearBars.tsx`, `next.config.mjs`, `public/media/hero-beranda/dji-03-1440.webp`, uji `src/lib/fe-68-hero-foto.test.ts`, jurnal ini.
- Langkah: Pilih foto dari berkas repo setelah bucket Storage kosong. Skrim `#111` 94% di kiri dan 92% di kanan. `next/image` fill, priority, sizes, blur, AVIF/WebP. Tanpa metadata lokasi/tahun/sumber, tanpa caption. Jika foto gagal, kontur polos kembali.
- Cara membuktikan: `npm test`, `npm run typecheck`, `npm run lint`. Kontras diukur pada piksel foto. Tangkapan elemen hero 1440 dan 390, terang dan gelap.
- Risiko: Jangan memakai stok Unsplash. Jangan foto wajah atau bendera partai. Jangan mengarang kredit. Jangan mengubah pita angka, batang kabupaten, atau tangga IRBI.

## Bacaan ulang niat

Bucket `cms-media` dan `laporan-media` kosong untuk klien anon. Foto BPBA di tabel kegiatan adalah URL WhatsApp dengan wajah, jadi tidak dipakai. Yang dipakai `hero-slides/03.jpg`, kredit di `public/media/CREDITS.md` sebagai foto aerial DJI dokumentasi Aceh Tangguh. Berkas itu tidak punya lokasi, tahun, atau sumber, jadi tidak ada caption.

## Perubahan

Hero statistik memakai turunan WebP 1440px dari slide 03. Skrim menutup foto. Judul, tubuh, kicker, dan grafik putih di kedua tema. Tombol "Telusuri per kejadian" putih dengan teks `#111`. Kontur 7% hanya saat foto gagal atau hilang. Baris filter tetap di luar bidang foto.
