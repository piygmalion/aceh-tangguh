## Niat

- Tujuan: Pohon git produksi punya `POST /api/cron/overlay-live` (Bearer `OVERLAY_CRON_SECRET`) dan `GET /api/overlay/{key}` yang hanya membaca `overlay_live_features` + ledger `overlay_live_refresh` (kontrak BE-8 / AN-5). Workflow yang sudah di `main` tidak lagi 404. Jangan menulis nilai secret. Jangan menebak Tatonas. Jangan migrasi baru.
- Berkas baru: `src/app/api/cron/overlay-live/route.ts`, `src/app/api/overlay/[key]/route.ts`, `src/lib/overlay-live.ts`, `src/lib/overlay-calon.ts`, `src/lib/overlay-layers.ts`.
- Berkas sunting bedah: `src/lib/types.ts` (`OverlayLayerKey`), `src/lib/supabase/types.ts` (`overlay_live_features`), `src/lib/sik/db-tables.ts` (tipe calon), `src/lib/security/production-config.ts` (peringatan nama `OVERLAY_CRON_SECRET`).
- Uji ikut: `src/lib/overlay-live.test.ts`, `src/lib/overlay-calon.test.ts`.
- Tidak diubah: rute `/api/overlay/tiles`, `/static`, `/maritime/*`, `MapOverlays`, Destana/SDB, migrasi baru, DATA-4, nilai secret.
- Langkah:
  1. Fallback: GET `[key]` hanya kunci live (`isOverlayLiveRefreshKey`). `maritime.ts` / `inarisk-tiles.ts` tidak ikut — mereka menarik cache/fixture di luar G14.
  2. Bedah tiga berkas tipe dari `origin/main`, bukan seluruh dirty tree.
  3. `npx tsc --noEmit`. Uji overlay-live + overlay-calon.
- Cara membuktikan: POST secret unset → 503 `not configured`; Bearer salah → 401. GET live memakai `loadOverlayLive`. `tsc` hijau.
- Risiko: mengirim seluruh diff `types.ts`; mengarang GeoJSON; POST cron sebelum deploy.
