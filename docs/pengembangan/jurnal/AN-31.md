## Naskah (kontrak DATA-20 / FE-26)

Naskah ini adalah kontrak. Jangan menambah opsi, dependensi npm baru, poligon administrasi/GADM, zona KRB I/II/III, atau migrasi `overlay_layers`. Jangan POST ke `data.bnpb.go.id` atau ImageServer. Jangan mengubah angka `ACEH_BBOX` atau `spatialRel` patahan.

### 1. DATA-20 — sumber: ImageServer `exportImage` amplop Aceh

**Perilaku.** Enam layanan yang sudah ada di `src/lib/inarisk-tiles.ts`:

| kunci | service |
| --- | --- |
| `inariskBahayaGempa` | `layer_bahaya_gempabumi` |
| `inariskBahayaTsunami` | `layer_bahaya_tsunami` |
| `inariskBahayaLongsor` | `layer_bahaya_tanah_longsor` |
| `inariskBahayaBanjir` | `layer_bahaya_banjir` |
| `inariskBahayaKarhutla` | `layer_bahaya_kebakaran_hutan_dan_lahan` |
| `inariskBahayaGunungApi` | `layer_bahaya_letusan_gunungapi` |

Asal: `https://gis.bnpb.go.id/server/rest/services/inarisk/{service}/ImageServer/exportImage`.

Satu GET per layer. Bukan kueri FeatureServer. Bukan ubin `{z}/{x}/{y}` di skrip ETL. Parameter wajib:

- `bbox` = `95.0,2.0,98.3,6.15` (`ACEH_BBOX` yang sama)
- `bboxSR=4326`, `imageSR=4326`
- `size=660,830`
- `format=png32`, `f=image`, `transparent=true`
- `interpolation=RSP_NearestNeighbor`

Jangan mengirim `renderingRule`. Probe 2026-09-06: `{"rasterFunction":"None"}` → HTTP 500. Renderer bawaan ImageServer + klasifikasi VALUE/RGB di bawah.

Helper URL murni: `inariskBahayaExportUrl(service)` di `scripts/lib/overlay-etl.mjs`.

### 2. DATA-20 — field kelas dan ambang

**Perilaku.** Nilai piksel `VALUE` setelah `None`:

- `a < 16` atau `VALUE` 0 atau 1 → buang (nodata / rendah)
- `VALUE` 2 → `kelas=sedang`
- `VALUE` ≥ 3 dan ≤ 10 → `kelas=tinggi`

Jika PNG bukan skala abu-abu kelas (kanal R, G, B berbeda > 3): pakai tabel warna InaRISK yang dikunci, bukan tebakan per layer:

- merah (`R ≥ 180`, `G < 80`, `B < 80`) → tinggi
- oranye (`R ≥ 180`, `80 ≤ G < 210`, `B < 80`) → sedang
- selain itu (kuning/hijau/transparan) → buang

Keenam layer, **termasuk gempa**, memakai ambang yang sama. Jangan cabang “hanya tinggi untuk gempa”.

---

### 3. DATA-20 — polygonize, gabung, sederhanakan, clip

**Perilaku.** Helper murni di `overlay-etl.mjs`, tanpa paket npm baru, tanpa GDAL:

1. `decodePngRgba(buffer)` — PNG8/PNG24/PNG32 via `node:zlib`.
2. `classifyInariskPixels(rgba, width, height)` → `Uint8Array` 0/2/3.
3. `polygonizeClassGrid(values, width, height, bbox)` — 4-connected; satu cincin luar per komponen; gabung per kelas menjadi **satu** `MultiPolygon` `sedang` dan satu `tinggi` (boleh hanya salah satu).
4. `simplifyRing(ring, 0.003)` — Douglas–Peucker, derajat. Satu epsilon.
5. `clipFeatureCollectionToBbox` yang sudah ada. Jangan helper clip baru. Jangan poligon admin.
6. Properti wajib: `layer`, `title`, `kelas` (`sedang`|`tinggi`), `fillColor` (`#C4A35A` sedang, `#B42318` tinggi — salinan hex, bukan impor TS).

Keluaran: `public/fixtures/overlays/bahaya-{gempa,tsunami,longsor,banjir,karhutla,gunungapi}-aceh.geojson`. Bukan PMTiles.

### 4. DATA-20 — gagal-nol

**Perilaku.** Unduh + decode + polygonize + filter + clip keenam layer dulu. Jika **salah satu** `features.length === 0`: `process.exit(1)` dan **jangan menulis keenam berkas**. Tidak ada `FORCE`. Hulu 520 / bukan PNG → sama: exit 1, jangan menimpa fixture lama.

Skrip: `scripts/fetch-inarisk-bahaya.mjs`. `package.json`: `fetch:inarisk-bahaya`.

Uji tanpa jaringan di `scripts/overlay-etl.test.mjs`: URL memuat `ACEH_BBOX` + `rasterFunction":"None"`; klasifikasi 2/3 tersimpan 1 dibuang; poligon menyeberang amplop ter-clip; koleksi 0 fitur ditolak penulis.

---

### 5. FE-26 — katalog fill + jalur static

**Perilaku.** Keenam kunci `kind: "fill"` di `OVERLAY_CATALOG`. Entri di `OVERLAY_STATIC_FIXTURES` dan `loadOverlayVector`. `fetchOverlayGeojson` memakai `overlayVectorApiPath(key)` (`/api/overlay/static/{key}` untuk fixture). Jangan `GET /api/overlay/{key}` untuk bahaya — rute itu hanya kunci live.

`pickOverlayHit` membaca `properties.kelas` ke `status`. Popup menampilkan kelas lewat kunci `krbSedang` / `krbTinggi` yang sudah ada.

Rute `/api/overlay/tiles/...` dan `isInariskRasterKey` **tetap**. UI tidak memanggilnya. Jangan hapus proxy. Jangan migrasi Supabase. Jangan menyentuh cron/ledger live.

`data-sources` entri `inarisk-bahaya-raster` diganti: fixture vektor clip Aceh, attribution BNPB InaRISK.

Uji: `overlayInteractiveLayerIds` memuat fill+line `inariskBahayaGempa`; `overlayVectorApiPath("inariskBahayaGempa")` = `/api/overlay/static/inariskBahayaGempa`; sumber `useOverlayGeojson` memuat `overlayVectorApiPath`.
