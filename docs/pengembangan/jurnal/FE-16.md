# FE-16 — popup Tanggapi: avatar, gelembung, aksesibilitas

Agent: frontend
Gelombang: 14
Status: selesai

## Niat

- Tujuan: Popup Tanggapi tetap overlay (tidak kembali ke hero). Pembaca layar membedakan tutup gelembung vs tutup panel. Fokus masuk panel saat buka dan kembali ke FAB saat tutup. Avatar terbaca bust civic di 56px tanpa cakram ganda. Animasi hormati `prefers-reduced-motion`.
- Berkas: `src/components/panduan/TanggapiAvatar.tsx`, `src/components/panduan/GuideBot.tsx`, `src/components/panduan/GuidePanel.tsx`, `messages/id.json`, `messages/en.json` (kunci baru `panduan.dismissInvite` saja), jurnal, STATUS.
- Tidak diubah: `HeroSection`, gerbang LLM, rute V1, kunci `open` / `close` / `askHero` / `heroHint` / `title`, `/peta` tetap tanpa widget.
- Langkah:
  1. SVG tanpa lingkaran latar; pin kompas di dada (~y=72); hapus `<title>` (sudah `aria-hidden`).
  2. Kunci `dismissInvite`. X gelembung dan Escape saat gelembung terbuka memakai itu (dismiss, bukan buka panel).
  3. Dialog: `aria-modal="true"`, perangkap Tab, fokus awal `#panduan-input`, fokus kembali ke FAB. Motion durasi 0 jika reduced-motion.
- Cara membuktikan: tes `shouldShowGuideBot` + `open-tanggapi.test.ts`; browser `/id` dan `/en` hero tanpa bust besar; X gelembung bukan *Tutup Tanggapi*; `/id/destana` FAB ada; `/id/peta` FAB tidak ada; chip Destana V1.
- Risiko: menimpa kunci i18n lama; mengembalikan undangan hero; oranye pada avatar.

## Bacaan ulang niat

Satu tiket UI. Kunci baru hanya `dismissInvite`. Fokus dan Escape tidak boleh membuka panel dari gelembung. Avatar tidak menambah cakram di dalam tombol yang sudah hijau. Tidak menyentuh retrieve/validator (tiket grounded berikutnya).
