- Tidak diubah: skema/migrasi SQL, `SIK_MODULES`, RLS, helper `is_staff` / `is_ops` / `is_walidata`, rute `/admin` Ringkasan (hanya taut tambahan), Daily Brief PII, angka korban.

## Kontrak

**Perilaku.** Staff yang lolos `requireStaffPage` membuka `/admin/operasi`. Bukan rute `/admin/pengguna`. Nav label “Dasbor data” / “Data dashboard”. Ringkasan `/admin` tetap. Tidak ada `SikModule` baru. Tidak ada migrasi. Tidak ada `POST`/`PATCH`/`DELETE`. Tidak ada `/api/admin/ops*`.

**Alur (Bolster).** Urutan visual: cakupan → transisi siklus → umpan modul → linimasa + papan peringkat. Siklus: masuk → ditinjau → disetujui → kejadian SIK → distribusi logistik (tahap disembunyikan jika modul tertutup). Progres = rasio selesai/total; 0/0 = 0, bukan NaN.

**Data.** Baca tabel yang sudah ada. Jangan `jawaban_json`, `pelapor_id`, `phone_enc`, `nama_enc`, NIK. Daily Brief hanya hitungan. Rehab penerima hanya hitungan.

**Scope.** `admin_kabkota`: filter kab yang sama dengan daftar SIK/laporan. `admin_desa`: Destana/PKD pada kode desa sendiri. Modul tanpa izin tidak dihitung dan tidak ditampil.

**i18n.** Kunci `admin.opsDash*` dan `admin.navOpsDash` di ID+EN. Komponen tidak hardcode label Indonesia.
