## Niat

- Tujuan: CRUD program Destana tanpa mengubah `pkd.ts`. GET/PATCH/PUT `/api/sik/destana/program`. Helper huruf a–q + korespondensi 32 indikator.
- Berkas: `src/lib/sik/destana-program.ts`, `src/app/api/sik/destana/program/route.ts`, `src/lib/sik/db-tables.ts` (tipe baru), `security/attack-surface.md` (daftar rute), jurnal, STATUS.
- Tidak diubah: `pkd.ts`, kuesioner, DATA-4, calon, SDB, crypto.
- Langkah:
  1. Konstanta AN-7: 17 aktivitas, peta 32→huruf, `instrumen_versi` `perka-1-2012` / `perban-7-2025`.
  2. Validasi kode desa 10 digit diawali `11`; tolak fasilitator/pembelajaran yang hanya 16 digit (NIK).
  3. GET: `requireModuleApi("destana")`. `kode` wajib kecuali `admin_desa` (pakai scope). `tahun` default tahun kalender. Balas `si`, 17 slot aktivitas (`belum` jika belum tersimpan), `penilaian_berikutnya` = tahun PKD desa + 3 atau null.
  4. PATCH `kind=si`, PUT `kind=aktivitas`: `rejectCrossOrigin`; tulis hanya `admin_desa` (kode = scope) atau `super_admin`. `sebaran` selalu = kode. Jangan terima koordinat.
  5. Kab: jika `kodeKabupaten` numerik, GET kode harus berawalan itu; jika bukan numerik dan `kode` ada, izinkan baca satu kode (sudah terlihat di PKD).
- Cara membuktikan: helper tes analis; rute di attack-surface; `tsc` hijau.
- Risiko: mengarang skor; POST nasional; menulis untuk kab.
