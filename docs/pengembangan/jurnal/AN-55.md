## Niat

- Tujuan: Mengunci brief harian sebagai **halaman pimpinan + kartu operasional**, hanya dari umpan yang sudah ada. Kekosongan tertulis, bukan dikarang. WhatsApp tetap pendek + tautan.
- Berkas: jurnal ini; STATUS; brief 02–04. Tiket ini tidak menyunting `src/`.
- Langkah: satu aturan per umpan; kamus belum-ada vs tidak-ada-dampak; prioritas umpan; kompatibilitas `summary` v1; non-tujuan.
- Cara membuktikan: setiap butir adalah aturan. BE/FE tidak menebak korban, KRB, `loggerKind`, atau status siaga resmi BPBA.
- Risiko: membuka G32; mengisi jarak permukiman; menimpa form nomor FE-48.

## Bacaan ulang niat

G31 tetap: cron 07:00 WIB, secret `DAILY_BRIEF_CRON_SECRET`, staf provinsi, GET publik tanpa PII, satu umpan mati tidak diisi dari umpan lain. V2 menambah struktur JSON di kolom `summary` yang sudah `jsonb`. Bukan migrasi tabel baru. Bukan LLM.

## Naskah

### 1. Keluaran

**Perilaku.** Satu halaman `/brief/[ymd]` = brief pimpinan (header, eksekutif, prioritas, tindakan) + kartu operasional (cuaca, gempa MAGMA, overlay gempa, hotspot, pos, kejadian). Dashboard teknis penuh dan brief 3–5 halaman ditunda. WA = bullet `feeds` + tautan; bukan isi kartu.

### 2. Versi JSON

**Perilaku.** `DailyBriefSummary.version === 2` wajib pada compose baru. `feeds` tetap ada (WA + pembaca v1). Jika `version` absen, UI memakai daftar feed G31. Jangan hapus baris `daily_briefs` lama.

### 3. Kamus kekosongan

**Perilaku.**

| Tulisan | Arti |
| --- | --- |
| `unavailable` / data tertunda | Query gagal atau `source !== live` |
| tidak ada pada umpan hari ini | Live + empty; 0 sah untuk overlay gempa |
| belum ada | Field tidak disediakan umpan |
| belum ada laporan | Belum ada laporan dampak/korban |
| belum terverifikasi | Ada indikator, belum konfirmasi lapangan |

Jangan menulis **tidak ada dampak** kecuali ada verifikasi lapangan di umpan (gelombang ini: tidak ada). Jangan menulis **0** saat query gagal.

### 4. Prioritas umpan

**Perilaku.** Label UI: “prioritas pemantauan umpan”, bukan status siaga BPBA. Maks 5 baris. Umpan `unavailable` tidak masuk tabel.

| Syarat | Prioritas |
| --- | --- |
| Kejadian ops live dan jumlah > 0 | tinggi |
| Sipongi live, ada titik, ada `high` | sedang |
| Sipongi live, ada titik, hanya medium | sedang |
| Cuaca live, tidak empty | sedang |
| MAGMA live, ada event | rendah |
| Overlay gempa live, count > 0 | rendah |
| Overlay gempa live, count = 0 | informasional |

`worstPriority` = tertinggi di tabel, atau `informasional` jika tabel kosong. Jangan memakai jumlah penduduk, KRB, atau IRBI.

### 5. Umpan

**Cuaca.** Highlight kartu PD: kabupaten, kondisi, `curah_hujan_mm`, periode, sumber, `fetched_at`. Angin hanya jika sudah tertulis di `kondisi`. Jangan WeatherNext.

**MAGMA.** Event kartu: magnitude_text, wilayah, waktu, koordinat_kedalaman, intensitas_mmi jika ada. Jika unavailable, jangan salin event sisa.

**Overlay gempa.** Baris `overlay_live_features` `bmkgQuakes` pada `brief_date` Jakarta: count + hingga 5 baris (lat/lng, occurred_at, properties yang ada). Query gagal → unavailable, bukan 0.

**Sipongi.** Titik kartu: kab/kec/desa, confidence, tanggal. Lat/lng hanya dari overlay jika query berhasil; jika tidak, null.

**Tatonas.** Highlight kartu: `pos_name`, `sensor`, `value`, `satuan`, `level`, `time_local`. Jangan `logger_kind` / DATA-4. Bahasa: “melewati ambang pemantauan”, bukan “ambang umpan”.

**Kejadian.** Hingga 5 baris `kejadian_operasi` `status = aktif`: nomor, jenis, nama, status, kab/kec/desa, waktu, lat/lng. Jangan `kejadian_korban` / angka meninggal. Jika query gagal, fallback `live_stats.active_incidents` (angka saja, tanpa kartu rinci).

**Maritim / DIBI / IRBI / KRB.** Tidak masuk brief.

### 6. Eksekutif dan tindakan

**Perilaku.** Lima slot templat dari field terisi; celah = “belum ada”. Tindakan jendela 1–3 jam hanya jika isu itu muncul di umpan hari itu (verifikasi kejadian, identifikasi hotspot, konfirmasi pos, imbauan cuaca jika kondisi petir/hujan lebat/angin, pantau laporan gempa dengan kamus belum ada laporan).

### 7. Delta kemarin

**Perilaku.** Bandingkan `feeds[].count` dengan `daily_briefs` tanggal-1 jika baris ada. Jika tidak ada, delta = null. Jangan mengisi dari umpan lain.

### 8. Non-tujuan

**Perilaku.** Jangan G32 LLM. Jangan OTP. Jangan DATA-4. Jangan POST nasional. Jangan P2 Juklak. Jangan peta situasional baru (tautan `/peta?overlays=` sah). Jangan menimpa FE-48. Jangan menulis nilai secret.
