# BE-81 — TTL cache cuaca 4 jam

Agent: backend
Gelombang: kemudian
Status: selesai

## Niat

- Tujuan: Konstanta TTL yang menulis `expires_at` pada `POST /api/weather/refresh` menjadi 4 jam. Keputusan pemilik Pygmalion.
- Berkas: `src/app/api/weather/refresh/route.ts` (satu angka), uji yang mengunci selisih itu, jurnal ini, satu baris STATUS.
- Tidak diubah: migrasi, workflow, jadwal cron, env, `cache-read.ts`, UI, `OVERLAY_WEATHER_LIKE_TTL_MS`, skrip `scripts/refresh-weather-cache.mjs`.
- Cara membuktikan: uji `expires_at` pada baris upsert = `fetched_at` + 4 jam; `npm test`, `tsc`, `lint`, `build`. Tidak ada SQL ke basis data hidup.

## Bacaan ulang niat

Route menghitung satu stempel `Date.now() + 4 jam` sebelum loop, lalu menyimpannya di `expires_at`. Kolom `fetched_at` tetap nilai dari prakiraan. Uji menyetel `fetched_at` pada saat fetch dan menuntut selisih 4 jam (toleransi 5 detik). Jadwal tetap `0 */3 * * *`, jadi TTL sekarang lebih panjang dari jeda cron.

## Perubahan

```diff
-  const expiresAt = new Date(Date.now() + 2 * 60 * 60 * 1000).toISOString();
+  const expiresAt = new Date(Date.now() + 4 * 60 * 60 * 1000).toISOString();
```
