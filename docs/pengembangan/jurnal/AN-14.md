## Naskah (penerimaan produksi G9+)

Satu perilaku per butir. Jangan menulis langkah serangan. Jangan mengulang isi SQL.

### 1. Migrasi wajib sebelum overlay / calon / SDB / Destana berguna

**Perilaku.** Produksi tidak berguna untuk overlay live, calon, SDB, atau program Destana sampai berkas ini diterapkan. Sebut nama berkas.

Tanpa `20260918_destana_dua_instrumen.sql`, GET/PATCH/PUT `/api/sik/destana/program` tidak punya tabel. Jangan menandai produksi siap Destana jika berkas itu belum hidup. Jangan menerapkan ulang `20260907`–`20260909`.

### 2. Secret overlay dan env PII (nama saja)

**Perilaku.** Cron overlay live memakai `OVERLAY_CRON_SECRET` dan `OVERLAY_REFRESH_URL`. Rotasi PII memakai `LAPORAN_PII_KEY_ID` dan `LAPORAN_PII_KEYS` (opsional). Jangan menulis nilai.

### 3. Tabel Destana belum ada → 500, bukan 200 kosong

**Perilaku.** Jika query `destana_si` / `destana_aktivitas` error (termasuk tabel belum ada), `src/app/api/sik/destana/program/route.ts` mengembalikan HTTP 500. Bukan 200 dengan payload kosong. Kebijakan BE-12; jangan diubah di tiket ini.

### 4. Path wajib di `security/attack-surface.md`

**Perilaku.** Inventaris harus memuat `/api/sik/destana/program`. Bukan prosedur serangan.

### 5. Non-tujuan

**Perilaku.** Jangan DATA-4. Jangan POST ke `data.bnpb.go.id`. Jangan membuka P2 Juklak. Jangan mengubah rumus PKD. Jangan menulis langkah exploit.
