## Niat

- Cara membuktikan: setiap larangan punya perilaku HTTP/UI; field boleh/tidak tertulis; salinan UI ID+EN tertulis; lisensi tertulis.

## Naskah (kontrak DATA-13 / BE-20 / FE-19 / AN-25)

### 1. Dua jalur

**Resmi (tidak diubah).** BMKG `adm4` → Open-Meteo → cache `weather_forecasts` → `weather-snapshot.json`. Rute: `GET /api/weather`, `GET /api/weather/[kab]`, `POST /api/weather/refresh` (`WEATHER_CRON_SECRET`). UI: `WeatherStrip`, `WeatherGrid`, `WeatherAttribution`, kartu Peringatan Dini cuaca. Tipe `WeatherSource` tetap `"bmkg" | "open-meteo" | "cached" | "fixture"`.

**Inovasi (baru, gagal sendiri).** WeatherNext 3 via Earth Engine (bukan Maps Platform Weather API). Rute: `GET /api/weather/inovasi`, `POST /api/weather/inovasi/refresh` (`WEATHER_INOVASI_CRON_SECRET`, bukan secret cuaca resmi). UI: `WeatherInovasiStrip` di bawah `#cuaca` di beranda. Fixture: `public/fixtures/weather-inovasi-snapshot.json`.

Dilarang: merge tubuh inovasi ke `/api/weather`; menambah `"weathernext"` pada `WeatherSource`; memanggil Earth Engine dari `getWeatherForecasts` atau dari browser.

### 2. Dasar aturan

- UU 31/2009: informasi MKG resmi dan peringatan keselamatan publik adalah kewenangan BMKG. Aplikasi daerah menampilkan, tidak mengganti.
- UU 24/2007: pesan yang mendorong tindakan datang lewat instansi berwenang. Model AI asing bukan saluran itu.
- Juklak 7/2023 + AN-4: `sumber_informasi` tidak dikarang. Calon kejadian hanya BMKG TEWS, MAGMA gempa, Sipongi, Tatonas. WN3 **bukan** calon.
- Playbook repo: daerah jangan membangun saingan nasional.
- Syarat Google WN3: eksperimen, bukan peringatan resmi; rujuk badan meteorologi nasional.

### 3. Field

| Field resmi | WN3 | Aturan |
| --- | --- | --- |
| `temperature_c` | `station_head_temperature_2m_*` (K) | Boleh di jalur inovasi setelah K − 273,15 |
| `humidity_pct` | tidak native | Boleh turunan Magnus dari T + titik embun. Null jika salah satu hilang |
| `weather_code`, `weather_desc_*`, `image_url` | tidak ada | Dilarang mengarang. Tidak ada di payload inovasi |
| `wind_speed_kmh` | `wind_speed_10m` (m/s) | Boleh setelah × 3,6 |
| `wind_direction_deg` | u/v (opsional) | G19 tidak wajib; jangan isi 0 fiktif |
| `precipitation_mm` | `imerg_tp_1hr_*` (m) | Boleh setelah × 1000 |
| petir / kode 95–99 | tidak ada | Dilarang masuk `scoreKab` |
| ikon BMKG | tidak ada | Dilarang `WeatherIcon` pada strip inovasi |

### 4. Geometri dan titik

Bbox: `ACEH_BBOX` `[95.0, 2.0, 98.3, 6.15]` (`src/lib/basemap.ts`), sama MAGMA. Bukan `ACEH_BOUNDS` laporan. Titik: 23 sentroid `kab-weather-registry.json`. Bukan kisi penuh. Bukan adm4.

Koleksi EE: `projects/gcp-public-data-weathernext/assets/weathernext_3_0_0_0p05deg` (suhu/titik embun, scale 5000) dan `…/weathernext_3_0_0_0p1deg` (hujan IMERG, angin 10 m, scale 10000). `forecast_hour ≤ 48`. Zarr 64 anggota dilarang di Next.js.

### 5. HTTP inovasi

`GET /api/weather/inovasi` hanya baca cache/fixture. Tidak memanggil BMKG, Open-Meteo, atau Earth Engine.

| Keadaan | Status | Tubuh |
| --- | --- | --- |
| Cache sah, ada titik | 200 | `status: "ok"`, `official: false`, titik terkonversi |
| Cache kedaluwarsa, masih ada titik | 200 | `status: "stale"`, `official: false`, titik terakhir — bukan angka baru |
| Fixture/cache `unconfigured` atau tanpa kredensial EE | 200 | `status: "unconfigured"`, `official: false`, `kabupaten_kota: []` |
| Dikonfigurasi, hulu gagal, tidak ada cache titik | 503 | `status: "upstream"`, `official: false`, `kabupaten_kota: []` |

Setiap tubuh inovasi wajib `official: false` dan `kind: "inovasi"`. Dilarang menaruh suhu/hujan/angin yang tidak berasal dari EE atau berkas mentah uji yang eksplisit (bukan fixture default).

`POST /api/weather/inovasi/refresh`: secret `WEATHER_INOVASI_CRON_SECRET`. Tidak ada secret → 503. Bearer salah → 401. EE tidak dikonfigurasi → 503 `unconfigured`, jangan menulis titik palsu. Jangan memakai `WEATHER_CRON_SECRET`.

GET publik inovasi: `Cache-Control` seperti overlay 200; tidak menambah fail-closed Upstash (itu akan mematikan strip di pratinjau). Cron tetap Bearer.

### 6. Salinan UI (wajib i18n)

Namespace `weatherInovasi`. Jangan menimpa `weather.attribution`.

| Kunci | id | en |
| --- | --- | --- |
| title | Konteks model AI (eksperimen) | AI model context (experimental) |
| pill | Bukan peringatan resmi | Not an official warning |
| lead | Ini bukan prakiraan atau peringatan dini BMKG. Untuk keselamatan publik, ikuti BMKG dan BPBA. | This is not a BMKG forecast or early warning. For public safety, follow BMKG and BPBA. |
| delayed | Lapisan eksperimen tertunda atau belum dikonfigurasi. Prakiraan resmi di atas tidak terpengaruh. | Experimental layer delayed or not configured. The official forecast above is unchanged. |
| attribution | WeatherNext 3 · Google DeepMind / Google Research. Data eksperimen. Informasi resmi: BMKG. | WeatherNext 3 · Google DeepMind / Google Research. Experimental data. Official information: BMKG. |

Strip di bawah `WeatherStrip` (`#cuaca`). Jangan di dalam kartu Peringatan Dini. Jika GET 503 / `unconfigured` / kosong: tampilkan `delayed`, jangan kartu suhu kosong yang terlihat seperti data.

### 7. Lisensi dan atribusi
