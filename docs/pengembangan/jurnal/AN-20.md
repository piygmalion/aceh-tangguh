## Bacaan ulang niat

Satu perilaku per butir. `matchesKabScope` dipakai juga calon overlay — fail-closed berlaku di sana.

## Naskah

### 1. matchesKabScope

- Bukan `admin_kabkota` → izinkan (provinsi / super_admin / desa / penilai tidak tersaring kab di fungsi ini).
- `admin_kabkota` tanpa `kode_kabupaten` dan tanpa `kabupaten` → **tolak**.
- Ada scope → lolos hanya jika `kode_kabupaten` atau `kabupaten` baris sama dengan scope.

Efek samping: `calonVisibleToOps` / terima-tolak calon tanpa wilayah menjadi tolak untuk kab. Disengaja.

### 2. Destana baca

`authorizeDestanaProgramRead`: jika `isKabScoped` dan scope kosong → 403 `scope_kabupaten`. Jika scope kode 4 digit dan `kode_desa` tidak berawalan itu → 403. Desa tetap `scope_desa`. Provinsi/super tetap lolos.

### 3. Matriks `/sik/resource`

Dari `20260907_sik_operasional.sql` + `RESOURCES` di rute. Kode memakai kunci `kejadian_row` untuk baris `kejadian+row`.

| resource | mode | aturan untuk admin_kabkota |
| --- | --- | --- |
| korban, pengungsi, distPersonil, distPeralatan, distKebutuhan | `kejadian` | Wajib `kejadian_id`. Muat header `kejadian_operasi`. `matchesKabScope` atau 403. Tanpa `kejadian_id` → 400. |
| kerusakan, rehab | `kejadian+row` | Jika ada `kejadian_id`, sama seperti `kejadian`. List tanpa id: saring `kode_kabupaten`/`kabupaten` = scope. Tulis: header atau kolom kab baris harus lolos. |
| personil, peralatan, kebutuhan, instansi, pengungsian, disabilitas | `row_kab` | List/mutasi: `matchesKabScope` pada kolom kab baris. Baris kab kosong = tidak lolos. |
| rehabMonitoring, rehabPenerima | `via_rehab` | Muat `rehab_kebutuhan` lewat `kebutuhan_id`. Lalu aturan `kejadian+row` pada induk. Tanpa induk → 400. |
| nomorPenting, pelatihan, permintaanPelatihan | `provincial` | Tidak disaring kab. Modul `publikCms` tetap. |

Provinsi/super_admin: tidak menambah saringan kab (modul tetap).

POST/PATCH/DELETE: origin tetap; payload kab asing → 403. Jangan revoke `is_staff` / `is_ops`.

### 4. Non-tujuan

Jangan DATA-4. Jangan P2 Juklak. Jangan mengubah rumus PKD.
