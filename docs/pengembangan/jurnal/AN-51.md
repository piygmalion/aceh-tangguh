# AN-51 — naskah GET PD baca L1

Agent: analis
Gelombang: ECC-C1
Status: siap-kode

Kontrak C1. Bukan AN-47. Bukan G36. Jangan DATA-4.

## Niat

- Tujuan: Mengunci satu perilaku: kartu MAGMA / Sipongi / Tatonas pada `GET /api/peringatan-dini` (dan rute kartu sejenis) **hanya membaca L1** (`overlay_live_features` + ledger `overlay_live_refresh`). Cron tetap scrape `no-store`. Agregat PD tetap HTTP 200. Overlay hidup tetap 200 vs 503 (AN-5 / AN-28).
- Berkas: jurnal ini; pointer STATUS / 02-backend / 04-analis / 07-konsep-caching. Kode = BE-37 / uji = AN-52.
- Langkah: tulis cabang ledger → kartu; baca ulang; jangan buka DATA-4 / merge cuaca / Upstash overlay.
- Cara membuktikan: setiap cabang AN-5 punya baris kartu; GET tidak memanggil `fetchMagmaLive` / `fetchSipongiLive` / `fetchTatonasLive`; cron `revalidateTag` `peringatan-*`.
- Risiko: menelan 503 overlay menjadi kartu kosong sah; mengarang gempa Bener Meriah; fixture Sipongi sebagai “tidak ada hotspot”; scrape pada GET.

## Bacaan ulang niat

Tulisan. Bukan opsi. `unstable_cache` L2 boleh membungkus **hasil SELECT**, bukan scrape. Jangan tabel SQL baru. Jangan menulis `overlay_calon_kejadian` dari GET PD. Jangan `magmaVolcanoes` pada kartu gempa. Cuaca PD tetap `getWeatherForecasts`. Maritim PD tetap `maritime_warning_cache`.

## Naskah

### Keputusan

GET PD MAGMA / Sipongi / Tatonas = **baca L1**. Peta kartu dari `overlay_live_features` + ledger `overlay_live_refresh` untuk kunci `magmaQuakes`, `sipongiHotspots`, `tatonasStations`. **Jangan** memanggil `fetchMagmaLive` / `fetchSipongiLive` / `fetchTatonasLive` dari jalur GET.

`unstable_cache` L2 boleh membungkus hasil SELECT, bukan scrape. Setelah cron overlay persist, panggil `revalidateTag("peringatan-magma")`, `revalidateTag("peringatan-sipongi")`, `revalidateTag("peringatan-tatonas")` (selain tag maritim yang sudah ada).

Tidak ada tabel SQL baru. Tidak ada Upstash sebagai store overlay. Tidak merge dengan `/api/weather`. Jangan menulis `overlay_calon_kejadian` dari GET PD. Jangan memakai `magmaVolcanoes` pada kartu gempa.

### Ledger → kartu PD

Cabang sama dengan `resolveOverlayLiveRead` (AN-5). **Jangan** meniru status HTTP overlay ke rute agregat PD (agregat tetap 200).

| Cabang overlay (AN-5) | Kartu PD |
| --- | --- |
| 200 segar, ada fitur | `source: "live"`, `stale: false`, isi dari baris |
| 200 kosong-sah (ledger `ok` + `feature_count === 0` + tanpa baris) | `source: "live"`, `stale: false`, `empty: true`, tanpa kejadian/titik karangan |
| 200 + stale (baris ada, kedaluwarsa atau ledger `ok: false`) | `source: "live"`, `stale: true`, tampilkan cache L1 |
| setara-503 (tanpa baris + bukan kosong-sah) | MAGMA → `unavailableMagmaCard`; Sipongi → `source: "unavailable"`, `stale: true`, `points: []` (bukan fixture sebagai “tidak ada hotspot”); Tatonas → `emptyTatonasCard({ source: "unavailable" })` |

**MAGMA.** `unavailable` tetap **tidak** menyalin kejadian terakhir jika L1 kosong. Jika L1 punya baris, menampilkan cache + `stale: true` **boleh** (berubah dari fail-closed scrape-GET). Jangan mengarang magnitudo. Kartu = **satu** kejadian Aceh terbaru menurut `occurred_at` / waktu di properties — bukan daftar overlay penuh.

**Sipongi.** Fixture `peringatan-sipongi.json` hanya jika SELECT L1 mustahil (tidak ada klien Supabase / lemparan baca lokal), dengan `source: "fixture"`, `stale: true`, `example: true`. Jangan memakai fixture ketika ledger setara-503 tetapi DB hidup.

**Tatonas.** Sorotan dari properties baris yang sudah ada (`pos_name`, `level`, `value`, `satuan`, `jenis` / `logger_kind` tersimpan). **Jangan** mengubah pemetaan `kd_logger` di `parse.ts` (DATA-4 tertahan). Tidak ada logger kamera 5.

### Perkaya properties cron (tanpa migrasi)

Kolom `properties` jsonb sudah ada. Pada persist cron MAGMA, tambah extras jika parser hulu punya: `datetime_wib` atau setara, `area`/`koter`, `mmi`, `merusak`, `magtype`, `latlon_text`. Sipongi: `desa`, `kecamatan`, `kabkota`, `confidence_level` di properties.

### Tidak berubah

- Cuaca PD tetap `getWeatherForecasts` / `weather_forecasts`
- Maritim PD tetap `maritime_warning_cache`
- GET overlay hidup tetap 200 vs 503 per AN-28
- `CALON_LAYER_KEYS` / sinkron calon hanya dari cron overlay, bukan GET PD
- Bentuk JSON lima kartu + i18n permukaan tidak berubah
