# FE-27 — popup konteks AI di dalam perkiraan cuaca

Agent: frontend
Gelombang: tindak lanjut FE-19
Status: selesai

## Niat

- Tujuan: Memindahkan salinan `weatherInovasi` (Konteks model AI) dari section beranda `#cuaca-inovasi` menjadi dialog yang dibuka dari chip “Eksperimen” di dalam `#cuaca`. Bukan section sendiri. Jalur data BMKG dan WeatherNext tetap terpisah.
- Berkas: `src/components/weather/WeatherInovasiStrip.tsx`; `src/components/weather/WeatherStrip.tsx`; `src/app/[locale]/page.tsx`; `src/lib/qk.ts`; `src/lib/weather-inovasi/isolation.test.ts`; `messages/id.json`; `messages/en.json`; jurnal ini.
- Langkah: hapus sibling `<WeatherInovasiStrip />` dari beranda jika ada; pasang komponen inovasi di header `WeatherStrip` sebagai pemicu + `Dialog`; fetch `/api/weather/inovasi` tetap hanya di file inovasi; tambah kunci `trigger` dan `triggerAria` tanpa menimpa salinan AN-24; perbarui tes isolasi agar menolak `<section>` / `#cuaca-inovasi` / sibling di `page.tsx`.
- Cara membuktikan: `/id` dan `/en` tidak menampilkan blok “Konteks model AI” di alur halaman; klik chip membuka dialog dengan judul, pill, lead, delayed/kartu, atribusi; kartu BMKG di `#cuaca` tidak berubah; `WeatherStrip` tidak menyebut `/api/weather/inovasi`.
- Risiko: menggabungkan fetch WN3 ke `WeatherStrip`; mengembalikan section sibling; menimpa `weather.attribution`; memasukkan WN3 ke Peringatan Dini / `scoreKab` / `WeatherIcon`.

## Bacaan ulang niat

Satu section cuaca (`#cuaca`). Disclaimer AN-24 hanya muncul setelah klik. `WeatherStrip` hanya mengimpor komponen; tidak memanggil rute inovasi. Payload unconfigured/503/kosong tetap teks `delayed`, bukan kartu suhu kosong. Kunci `title`/`pill`/`lead`/`delayed`/`attribution` tidak diubah. DATA-4 tidak dibuka.
