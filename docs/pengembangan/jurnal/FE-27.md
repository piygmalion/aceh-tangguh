## Niat

- Tujuan: `AreaProfilPanel` menjadi kartu tengah-kanan. Kabupaten/kecamatan: populasi + korban + kerusakan + tombol Lihat Detail. Desa: korban/kerusakan atau sensus 3×3 jika dampak kosong. Buka di level klik.
- Berkas: `src/components/map/AreaProfilPanel.tsx`, `src/lib/area-profil-ia.ts`, `messages/id.json`, `messages/en.json`.
- Langkah: tes `desaShowsCensus` + view-on-open → restyle panel.
- Cara membuktikan: tes unit + browser modal Pidie/Tangse/desa.
- Risiko: Jangan teks kondisi bebas yang tidak ada di API. `mengungsi` tidak ada di `MetricBundle` — tidak dikarang.
