# BE-75 — kode alasan pada kartu MAGMA tidak tersedia

Agent: backend
Gelombang: kemudian
Status: selesai

## Niat

- Tujuan: Kartu MAGMA gagal-tertutup menambah field opsional `reason` berisi kode pendek, supaya kegagalan unduh produksi terlihat. Perilaku gagal-tertutup tidak berubah: `empty`, `stale: true`, `source: "unavailable"`, `event: null`. Respons `source: "live"` tidak membawa `reason`. UI klien tidak berubah.
- Berkas:
  - `src/lib/peringatan-dini-types.ts` (`MagmaCard.reason`, `unavailableMagmaCard`)
  - `src/lib/peringatan-dini/magma-live.ts`
  - `src/lib/peringatan-dini/magma.ts` (menyambung ke GET)
  - `src/lib/overlay-live.ts` (hanya membaca kolom `error` yang sudah ada)
  - `src/app/api/peringatan-dini/magma/route.ts` dan `src/app/api/peringatan-dini/route.ts` (tetap mengembalikan kartu; field ikut JSON)
  - uji `src/lib/peringatan-dini/magma-reason.test.ts`
  - jurnal ini
- Langkah:
  1. Kode hanya dari kelas galat atau status HTTP: `upstream_<status>` (termasuk `upstream_403`), `timeout` (`AbortError` / `TimeoutError`), `json_unreadable`, `empty`, `network`, dan `unreadable` untuk umpan HTML tanpa `markersGempa`.
  2. Satu kode per sumber yang dicoba: `maps`, `vsi`, `home`, `vsi-home`. Contoh `maps:upstream_403;vsi:timeout`.
  3. Jangan menyalin URL, header, atau tubuh respons. Ledger lama yang masih berisi URL tidak disalin ke kartu.
  4. GET tetap baca overlay. Alasan unduh hanya menempel bila kartu `unavailable` dan teks ledger lolos daftar kode.
- Cara membuktikan: uji tiap kode; `tsc`, `npm test`, `lint`, `build`.
- Risiko: menyalin tubuh atau URL ke JSON publik; mengubah kartu live; mengisi gempa lama saat gagal.

## Bacaan ulang niat

Niat bisa dijalankan tanpa menebak Tatonas, zona KRB, atau korban. Field aditif. Sumber `maps` / `vsi` adalah dua URL maps yang sudah ada; `home` / `vsi-home` adalah dua beranda HTML yang sudah dicoba. Daftar `/earthquake/list` tetap pengayaan dan tidak masuk alasan. GET tidak mengunduh MAGMA.

## Perubahan

- `MagmaCard.reason` opsional. `unavailableMagmaCard` hanya mengisinya jika teks lolos daftar kode.
- `fetchMagmaQuakeRaws` melempar `maps:upstream_403;vsi:timeout;home:…;vsi-home:…`. Daftar gempa opsional tidak masuk alasan. Pesan galat tidak lagi memuat URL.
- Kartu `source: "live"` membuang `reason`, termasuk bila pemanggil menyisipkannya.
- GET tetap SELECT overlay. `refreshError` dari kolom `error` yang sudah ada menempel hanya pada kartu `unavailable`, dan hanya jika sudah berupa kode. Teks ledger lama yang berisi URL dibuang.
