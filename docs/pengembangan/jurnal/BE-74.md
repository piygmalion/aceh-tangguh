# BE-74 — MAGMA netral, Tatonas fresh_count/alert_count, MAGMA tidak tersedia

Agent: backend + UI minimum (satu PR, diminta koordinator)
Gelombang: kemudian
Status: draf

## Niat

- Tujuan: Kartu gempa MAGMA tidak lagi menulis WASPADA dari magnitudo. WASPADA/AWAS hanya jika umpan hulu sendiri membawa level itu. Pengambil `magmaQuakes` membaca bentuk umpan yang benar-benar dipublikasikan situs MAGMA sekarang, dan tetap gagal tertutup (kosong + basi, tanpa gempa lama) jika unduhan gagal. Kartu Tatonas menambah `fresh_count` dan `alert_count` tanpa mengubah `highlights` atau kolom lama. Salinan UI mengikuti ketiga cabang itu.
- Berkas:
  - `src/lib/peringatan-dini/magma-parse.ts`
  - `src/lib/peringatan-dini/magma-live.ts`
  - `src/lib/overlay-live.ts` (hanya `fetchMagmaQuakes`)
  - `src/lib/peringatan-dini/overlay-cards.ts` (stale pos dari `occurred_at` yang sudah ada)
  - `src/lib/tatonas/parse.ts`, `src/lib/tatonas/types.ts`
  - `src/lib/peringatan-dini/card-copy.ts` (keputusan salinan, tanpa React)
  - `src/components/beranda/PeringatanBento.tsx`
  - `messages/id.json`, `messages/en.json`
  - uji di `src/lib/peringatan-dini/` dan `src/lib/tatonas/`
  - jurnal ini + tangkapan `docs/pengembangan/jurnal/be-74/`
- Langkah:
  1. Ubah fallback `magmaTone` menjadi netral. Jangan menambah ambang magnitudo. AN-4 sudah menulis bahwa situs tidak punya kebijakan magnitudo minimum; `mag >= 3` / `mag >= 5` di kode bukan aturan resmi hulu. MMI teks bukan level WASPADA. Level eksplisit `WASPADA` / `SIAGA` / `AWAS` pada kolom level umpan boleh mewarnai kartu.
  2. Buktikan bentuk umpan hidup (URL, status, cuplikan) lalu arahkan fetcher ke JSON publik yang dipakai beranda MAGMA sendiri (`/_api/home/maps` dan `/_api/earthquake/list`), dengan cadangan HTML `markersGempa` jika masih ada. Payload tidak terbaca melempar, tidak mengosongkan layer sebagai keberhasilan.
  3. `fresh_count` = pos yang diperbarui dalam 15 menit (`TATONAS_STALE_MS` yang sudah ada). `alert_count` = pos segar yang levelnya WASPADA atau AWAS. `highlights` tetap.
  4. UI: `fresh_count === 0` → "Data pos belum diperbarui · {menit} mnt", warna abu-abu, bukan hijau AMAN. `alert_count === 0` → "Seluruh pos pantau normal". Selain itu tampilkan `alert_count`. MAGMA netral abu-abu tanpa kata WASPADA. `source === "unavailable"` → "Data gempa tidak tersedia".
- Cara membuktikan: uji M2.7 (dengan MMI), M4.9, M5+, magnitudo kosong; uji pos semua basi, sebagian segar semua normal, sebagian segar WASPADA/AWAS; `tsc`, `npm test`, `lint`, `build`. Tangkapan 390 dan 1440.
- Risiko: mengosongkan layer MAGMA jika JSON 200 dianggap daftar kosong; menyalin gempa lama saat gagal; mengarang ambang; mengubah fixture/env/migrasi.

## Bacaan ulang niat

Niat bisa dijalankan tanpa menebak kode perangkat Tatonas, zona KRB, atau korban. Ambang 15 menit sudah `TATONAS_STALE_MS`. Level pos sudah dihitung `levelFromColor`. Tidak ada ambang magnitudo baru. Fetcher gagal harus melempar, bukan mengembalikan daftar kosong. Cuplikan umpan ditulis dari permintaan hidup, bukan dari ingatan. UI hanya menyalin field baru; `highlights` tidak dipotong ulang.
