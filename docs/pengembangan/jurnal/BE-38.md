# BE-38 — undangan staf: redirectTo + confirm + resend

Agent: backend
Gelombang: tindak lanjut verifikasi email staf
Status: selesai

Kontrak: [AN-53](AN-53.md).

## Niat

- Tujuan: Undangan Auth mengarah ke `/auth/confirm`, `verifyOtp` memakai `token_hash`, GET users memuat `emailConfirmed`, Super Admin dapat kirim ulang.
- Berkas: `src/lib/auth/email-invite.ts`, `src/app/api/admin/users/route.ts`, `src/app/api/admin/users/[id]/resend-invite/route.ts`, `src/app/auth/confirm/route.ts`, `src/middleware.ts` (kecualikan `/auth`), `src/lib/auth/email-invite.test.ts`, jurnal. **Pengecualian wilayah:** `src/lib/auth/`, `src/app/auth/`, `docs/vercel.md`.
- Tidak diubah: password di body undangan, OTP publik, migrasi, helper SQL.
- Langkah: helper murni; POST `redirectTo`; GET confirm; POST resend; middleware skip intl.
- Cara membuktikan: `npm test` helper + user-management; `tsc`.
- Risiko: open-redirect; PKCE pada invite; menimpa G36.

## Bacaan ulang niat

`type` hanya `invite`|`email`. Gagal → login `invite_invalid`. Rate limit GET confirm per IP. `/auth` tidak di-prefix locale.
