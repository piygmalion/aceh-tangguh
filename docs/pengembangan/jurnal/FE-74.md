# FE-74 — roda lembar, akordeon Laporkan, kredit peta

Agent: frontend
Gelombang: visual
Status: diverifikasi

## Niat

- Tujuan: Di lembar peta telepon, roda manual menggulir badan lembar. `deltaMode` garis menjadi piksel (sekitar 16px per baris). `deltaMode` halaman menjadi tinggi klien badan lembar. Momentum trackpad (delta piksel kecil, termasuk pecahan) ikut menggulir dan tidak mengubah zoom peta. Kepala dan pegangan lembar tetap `user-select: none`. Di laci navigasi 390, submenu Laporkan menjadi akordeon sebaris: inden 28px, baris 44px, `aria-expanded` pada tombol. Saat lembar setinggi penuh, kredit OSM/Carto tetap terlihat (baris pendek di kepala lembar boleh).
- Berkas: `src/lib/map-sheet.ts`, `src/components/map/MapFeatureSheet.tsx`, `src/app/globals.css`, `src/components/laporan/ReportLaporDropdown.tsx`, `src/lib/fe-74-sheet-nav.test.ts`, jurnal, STATUS. Uji yang mengunci string lama hanya disesuaikan jika pemanggilan berpindah ke fungsi yang sama.
- Langkah: Ubah delta roda jadi piksel menurut mode, simpan sisa pecahan supaya momentum trackpad tidak hilang, dan `preventDefault` tetap pada roda di dalam lembar. Akordeon `shape="row"` membuka tautan di bawah tombol, bukan panel absolut. Saat henti penuh, salin teks tautan atribusi peta yang sudah ada ke kepala lembar.
- Cara membuktikan: `npx tsc --noEmit`, `npm test`, `npm run lint`, `npm run build`. Tangkapan 390 (lembar penuh dengan kredit, laci Laporkan) dan 1440 (kredit peta desktop tetap di peta).
- Risiko: Baris kredit menambah tinggi kepala lembar. Akordeon hanya untuk `shape="row"`; menu desktop tetap panel. Jangan mengubah tema bawaan, data, API, ubin, atau berkas basemap.

## Bacaan ulang niat

Badan lembar adalah `[data-sheet-body]`. Halaman roda memakai `clientHeight` elemen itu, bukan tinggi jendela. Garis 16px ada di `sheetWheelDelta`; sisa pecahan disimpan di `sheetWheelStep` supaya deretan delta trackpad di bawah 1px tetap menggeser `scrollTop`. MapLibre memanggil `preventDefault` hanya pada wadah kanvas. Pendengar lembar di `window` membatalkan roda yang sasarannya di dalam lembar. `user-select: none` sudah ada pada kepala dan pegangan. Laci 390 memakai `ReportLaporDropdown` dengan `shape="row"` sebagai akordeon. Henti penuh menaruh kontrol atribusi di `z-index: 20`, di bawah lembar, jadi kredit disalin dari simpul `.maplibregl-ctrl-attrib-inner` yang sudah dipasang peta, tanpa menyunting `basemap.ts`.
