## Niat

- Tujuan: Memperbaiki gulir sapaan Tanggapi, tinggi kartu peta, tautan Sumber, kontras kicker, laci menu 390, dan sisa FE-68. Palet Peudeung v2 dan Plus Jakarta Sans tetap. Tidak ada warna partai atau bendera. Tidak mengarang data.
- Berkas: `GuidePanel.tsx`, `GuideBot.tsx`, `MapFeatureCard.tsx`, `MapWorkspace.tsx`, `MapViewport.tsx`, `MapSettings.tsx`, `SiteNav.tsx`, `globals.css`, `HeroPhotoBackdrop.tsx`, `DataHero.tsx`, `MetricSpark.tsx`, `RisikoLadder.tsx`, `FiturSection.tsx`, `PetaTeaserSvg.tsx`, `peta-teaser-paths.ts`.
- Langkah: Gulir ke awal pesan. Kartu peta `max-height: calc(100dvh - 6rem - 32px)` dan gulir di dalam, judul + × lengket. Tautan hostname bergaris 1px offset 2px plus ikon 12px. Teks polos senada label Sumber. Kicker `text-dim`. Tutup panel saat `goTour("/peta")`. Laci menu layar penuh di bawah `lg`. Caption satu baris di `lg+`. Pita angka dipadatkan di 390. Garis 1px `#8E1224` di bawah header. Urut IRBI di klien. `aria-label` Pengaturan lewat `t("settings")`. Path teaser dari fixture batas kabupaten.
- Cara membuktikan: `npm test`, `npm run lint`, `npm run build`. Tangkapan terang 1440 dan 390 di `docs/pengembangan/jurnal/fe-70/`.
- Risiko: Gulir `scrollIntoView` ikut menggeser halaman. Kartu tinggi menutup zoom; z-index kontrol dinaikkan. Path teaser terlalu disederhanakan sampai pulau hilang.

## Bacaan ulang niat

Sapaan yang harus kelihatan adalah kalimat darurat di awal briefing peringatan, bukan dasar panel. Sumber tetap blok terakhir. Kontrak `/api/irbi` tidak diubah; urutan desc dibuat di `RisikoLadder`. Path teaser berasal dari `public/fixtures/boundaries-aceh-kab.geojson`, bukan gambar tangan. Gelembung Tanggapi sudah `hidden` di bawah `sm`, jadi di 390 tidak menutup tick 26.
