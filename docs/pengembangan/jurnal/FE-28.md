Agent: frontend

## Niat

- Tujuan: Samakan bahasa interaksi chrome navbar. Oranye (`--accent`) hanya muncul saat hover, `:focus-visible`, tekan (`:active`), rute aktif, atau dropdown terbuka. Laporkan istirahat sama seperti Peta / Data / Siaga — bukan pil isi oranye permanen. Locale terpilih tetap sage (`--primary`).
- Berkas:
  - `src/lib/nav-chrome.ts` (baru)
  - `src/lib/nav-chrome.test.ts` (baru)
  - `src/components/SiteNav.tsx`

  - jurnal ini, lalu STATUS saat tutup
- Tidak diubah: HEX palet, hero, footer, tombol Lapor di body, IA grup Peta · Data · Siaga, shadcn `Button` di SiteNav, DATA-4, overlay.
- Langkah:
  1. Baca ulang niat.
  2. Tes dulu: helper mengunci token accent (bukan primary) untuk section; Lapor bukan CTA isi-oranye; SiteNav tetap Auth/Locale/Theme.
  3. Helper `navInteractiveClass({ active, open, shape })` + hover utilitas accent.
  4. SiteNav / Lapor / wordmark memakai helper; NavGroup + Lapor tutup klik luar dan Escape.
  5. Locale: terpilih sage, opsi lain hover oranye, type floor 13px. Theme + Auth trigger/item hover oranye (logout tetap danger; role chip tetap sage).
  6. Update design-system: oranye chrome = interaksi; isi oranye tetap CTA halaman + mark hero.
- Cara membuktikan:
  - Tes sumber nav-chrome, site-nav-ia, shadcn-fase3.
  - Browser `/id`, `/id/peta`, `/id/destana`, `/id/lapor`: hover tiap item; Siaga aktif di destana; Laporkan aktif di lapor; tidak ada dua isi-oranye; dropdown tutup klik luar + Escape; menu mobile; light + dark; locale terpilih tetap sage.
- Risiko:
  - Mengubah CTA hero / Participation — tidak dilakukan.
  - Memakai shadcn Button di SiteNav — dilarang (kunci fase 4/5).
  - Membuat Siaga terlihat status waspada — dicegah resep yang sama untuk semua section.

## Bacaan ulang niat
