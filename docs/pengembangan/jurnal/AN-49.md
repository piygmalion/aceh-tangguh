# AN-49 — naskah unggah foto sampul CMS

Agent: analis
Gelombang: 36
Status: selesai

Tulisan. Bukan kode pada tiket ini. Jangan menimpa BE-2, `POST /api/laporan/upload`, jurnal AN-45, AN-ECC-6 / C1, AN-41, atau DATA-4. DATA-28 / BE-36 / FE-51 / AN-50 menjalankan naskah ini setelah bacaan ulang. Jangan memakai ID AN-45 / AN-46 / AN-47 / AN-48 / BE-34 / BE-35 / FE-50.

## Niat

- Tujuan: Mengunci saluran **unggah gambar sampul oleh super admin** supaya CMS tidak bergantung pada URL asing, tanpa membuka unggah publik baru dan tanpa mencampur objek ke `laporan-media`.
- Berkas: jurnal ini; baris G36 di `STATUS.md`, `00-protokol.md`, brief `01`–`04`. Tiket ini tidak menyunting `src/`.
- Langkah: tulis aturan tunggal per butir; baca ulang; jangan menebak `loggerKind`, zona KRB, atau angka korban.
- Cara membuktikan: DATA/BE/FE dapat dijalankan tanpa menebak bucket, MIME, gerbang, atau cara menampilkan gambar di `/publikasi`.
- Risiko: bucket publik + path tebakan; SVG sebagai XSS; EXIF GPS pada sampul; menaikkan kuota `laporan-upload`.

## Bacaan ulang niat

Hanya JPEG/PNG/WebP. Hanya super admin, sama dengan rute CMS yang sudah ada. Objek boleh dibaca publik lewat URL Storage karena sampul sudah tampil di halaman publik; path UUID. Bukan PDF, bukan video, bukan poligon KRB.

## Naskah

### 1. Saluran

**Perilaku.** Satu rute `POST /api/admin/cms/upload` (multipart). Bukan `POST /api/laporan/upload`. Bukan TUS. Bukan unggah langsung dari browser ke Supabase dengan kunci anon. Respons JSON: `{ path, bucket, publicUrl, size, mime }`. `bucket` selalu `cms-media`. `path` berbentuk `sampul/{uuid}.{ext}` (ext dari MIME hasil enkode, bukan nama berkas klien).

### 2. Otorisasi

**Perilaku.** Sama dengan `GET/POST /api/admin/cms/publikasi`: `requireSuperAdminApi`. Bukan `admin_kabkota`. Bukan modul `cms` longgar tanpa super admin. `rejectCrossOrigin` pada POST. Tanpa sesi / bukan super admin → 401/403 seperti rute CMS lain. Jangan `guardPublicPost` (itu kuota pelapor; AN-45 mengunci kuota IP hanya untuk POST publik).

### 3. Berkas dan MIME

**Perilaku.** Field form `file` wajib. Cap **5 MiB** pada byte asli sebelum enkode. MIME dari **magic bytes**, bukan `File.type`. Allowlist: `image/jpeg`, `image/png`, `image/webp`. Selain itu → 400. JPEG/PNG/WebP lewat `reencodeImageWithoutMeta` (sudah ada). Gagal enkode → 400, tidak diunggah. Buffer Storage = hasil enkode (bukan byte-identik JPEG ber-EXIF).

### 4. Bucket dan RLS

**Perilaku.** Bucket baru `cms-media`. `public = true` (GET objek by path tanpa auth, untuk `<img>` di `/publikasi`). `file_size_limit` 5 MiB. `allowed_mime_types` tiga MIME di atas. Kebijakan: anon **tidak** INSERT/UPDATE/DELETE. SELECT objek boleh (bucket publik). Tulis hanya `service_role` dari rute Next. Jangan kebijakan `is_ops()` dari `laporan-media`. Jangan sunting migrasi `20260826` / `20260914`.

### 5. Kolom yang boleh diisi URL hasil

**Perilaku.** FE menyalin `publicUrl` ke `publikasi_kegiatan.foto_sampul_url` dan/atau `foto_sampul_thumbnail_url`. URL asing yang sudah ada tetap sah (bukan migrasi isi). Jangan mengubah skema kolom. Jangan menulis `krb_dokumen.url`. Jangan menulis `dokumentasi_url` Juklak. Jangan angka korban di metadata objek.

### 6. Non-tujuan

**Perilaku.** Jangan video, PDF, SVG, HTML, ZIP. Jangan GC orphan CMS. Jangan signed URL. Jangan Image Transformation berbayar. Jangan PMTiles / S3 tiles. Jangan merubah kuota laporan 20/jam. Jangan DATA-4. Jangan POST nasional. Jangan P2 Juklak. Jangan G32. Jangan menimpa FE-49 / AN-44. Jangan C1 cache PD (AN-47 / BE-35).

### 7. Inventaris dan uji (AN-50)

**Perilaku.** Daftarkan `POST /api/admin/cms/upload` di `security/attack-surface.md` sebagai rute **staf**, bukan POST publik. Uji: super admin 200 setelah enkode; anon 401/403; MIME palsu 400; >5 MiB 400; laporan-upload tidak berubah.
