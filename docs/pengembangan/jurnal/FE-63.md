## Niat

- Tujuan: Menerapkan palet Peudeung v2 yang dikunci pemilik. Chrome (terang dan gelap) hidup di `globals.css`. Status satu set hibrida. Konstanta data peta tidak di-alias. Beranda FE-62 ikut terwarnai: strip darurat, band angka DIBI, eyebrow.
- Berkas:
  - `src/app/globals.css`
  - `src/lib/chart-colors.ts` (hanya `STATUS_HEX`)
  - `src/lib/village-distribution-lod.ts` (garis tepi wilayah)
  - `src/lib/map-marker-chrome.ts` (cluster tetap palet data)
  - `src/lib/area-layers.ts`, `src/components/map/MapViewport.tsx`, `src/components/map/MapToolbar.tsx` (IRBI/KRB tetap palet sumber)
  - Komponen chrome: `SiteNav`, strip darurat, `Chip`, `button`, hero DIBI, kartu peringatan, footer, legenda status peta, dasbor operasi
  - `messages/id.json`, `messages/en.json`
  - Uji yang mengunci hex lama (`shadcn-setup`, garis tepi, cincin cluster) plus uji kunci palet
  - Jurnal ini dan `docs/pengembangan/STATUS.md`
- Langkah:
  1. Token chrome terang/gelap sesuai token map. Alias lama (`forest`, `sage`, `gold`, `orange`, `tangerine`, `bnpb-orange`, `burnt`, `teal`, `paper-warm`) satu rilis menunjuk token baru.
  2. `--status-*` = `--map-status-*`. Komentar: pendekatan warna PVMBG, bukan hex resmi. Garis tepi chip `#111111`. Bilah Awas gelap putih.
  3. `STATUS_HEX` ke skala hibrida. `COLOR_TOKENS`, `FOREST_SCALE`, legenda maritim, overlay, dan cluster tidak di-alias. IRBI/KRB tetap memakai token sumber yang sudah ada.
  4. `AREA_OUTLINE_COLOR` `#111111` @ 35% pada basemap terang dan `#FFFFFF` @ 30% pada basemap gelap. Lebar garis tidak berubah.
  5. Strip: 112 dan 117 saja. Slot Pusdalops menampilkan belum ada. Band DIBI: angka putih, garis atas merah 3px; tanpa sumber menampilkan belum ada, bukan 0.
  6. Highlight hero jadi bidang merah + teks putih. Chip forest/approved jadi chip tinta. Tombol `--accent` tinta. Destruktif outline + ikon. Zona status tanpa tombol merah.
- Cara membuktikan: `npm run lint`, `npm run typecheck`, `npm test`. Lalu beranda, `/peta`, kartu Peringatan Dini, dan halaman admin, terang dan gelap, desktop dan 390px.
- Risiko: Uji yang mengunci hex hutan/oranye di `globals.css` harus ikut token baru. `layer-colors.test.ts` tetap hijau karena `COLOR_TOKENS` tidak berubah. Jangan mengarang nomor Pusdalops atau angka korban.

## Bacaan ulang niat

Token map adalah sumber nilai. Kunci implementasi menimpa opsi “hibrida vs murni” yang masih terbuka di token map: status satu set hibrida. `STATUS_HEX` berubah; pemakai yang bukan status (IRBI, KRB, cluster) dilepas dari `STATUS_HEX` supaya palet sumber dan cluster tidak ikut bergeser. Nomor pada strip hanya 112 dan 117. Basis PR tetap cabang FE-62 sampai #113 merge.

## Perubahan

Token chrome terang dan gelap di `globals.css`, termasuk alias lama satu rilis. `STATUS_HEX` mengikuti skala hibrida. IRBI, KRB, dan cincin cluster tetap di `COLOR_TOKENS`. Garis tepi wilayah membedakan basemap terang dan gelap. Strip darurat, kop merah, band angka DIBI, chip status, dan legenda peta ikut palet yang dikunci.
