Agent: frontend

Bukan pemetaan `loggerKind` Tatonas. Jangan mengarang kode BPS/Kemendagri. Jangan menambah kamus Kemendagri baru. Jangan merancang ulang chrome Lokasi (GPS).

## Niat

- Tujuan: Pada langkah Lokasi (GPS) laporan bencana dan laporan penanganan, Kabupaten/Kota, Kecamatan, dan Desa/Gampong dipilih berjenjang dari kamus yang sudah ada. Memilih kab hanya menampilkan kec-nya; memilih kec hanya menampilkan desa-nya. Mengosongkan induk mengosongkan anak.
- Berkas:
  - `src/lib/laporan/wilayah-cascade.ts` + `wilayah-cascade.test.ts` — opsi kab dari registri 23, saring kec/desa, kosongkan anak, path API profil_desa yang sudah ada.
  - `src/components/laporan/WilayahCascadeFields.tsx` — tiga `<select>` asli (pola `FormFieldRenderer`).
  - `src/components/laporan/GpsCapture.tsx` — ganti input bebas kab/kec/desa; GPS/peta/lat-lng tidak diubah.
  - `src/components/laporan/ReportKejadianForm.tsx` / `ReportPenangananForm.tsx` — tetap memakai `GpsCapture` (tanpa salinan UI).
  - `messages/id.json`, `messages/en.json` — kunci placeholder/disabled/loading baru di `laporForm`.
  - jurnal ini, `STATUS.md`.
- Tidak diubah: skema `laporan_*` (tetap nama), `applyLokasiCoords`, `LokasiMapPicker`, AreaProfil/FE-55, `ACEH_KABUPATEN_REGISTRY`, DATA-4 Tatonas.
- Sumber data (jangan mengarang):
  - Kab/kota: `ACEH_KABUPATEN_REGISTRY` (23, `kode_sik` + `nama`).
  - Kecamatan: `GET /api/profil-desa/kabupaten?kode_kabupaten=` → `kecamatan_list` (kode 6 digit yang sudah ada, atau nama saja jika kode null).
  - Desa: `GET /api/profil-desa/kecamatan?kode_kecamatan=` atau nama kab+kec → `desa[]` (`kode` 10 digit yang sudah ada; empat baris null-kode memakai `id`, bukan kode karangan).
- Langkah:
  1. Uji RED: saring kab→kec→desa; induk kosong mengosongkan anak; opsi induk salah tidak muncul; tidak ada kode karangan; GpsCapture bukan input bebas.
  2. Helper + UI minimum; submit tetap `{ kabupaten_kota, kecamatan, desa }` nama.
  3. Quality + tilikan `/id/lapor/kejadian` dan `/id/lapor/penanganan` (+ `/en` jika komponen yang sama).
- Cara membuktikan:
  - `node --import tsx --test src/lib/laporan/wilayah-cascade.test.ts`
  - `npm test`, `npm run typecheck`, `npm run lint`
  - Browser: pilih kab → opsi kec hanya anaknya; pilih kec → opsi desa hanya anaknya; kosongkan kab → kec+desa kosong/disabled.
- Risiko: mengarang kode untuk poligon slug-only; menimpa FE-55; memecah chrome shadcn; memanggil query key terlarang (`kode_desa`).
