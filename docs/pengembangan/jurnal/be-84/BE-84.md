## Niat

- Tujuan: Satu PR draf. Daily Brief pindah ke berkas migrasi `pg_cron` tanpa apply. Workflow overlay dan Daily Brief menjadi cadangan manual dengan guard. Cron overlay melaporkan status per lapisan dan membalas 503 bila ada yang gagal. Ambang kesegaran K3+D5 berstatus usulan, belum dikunci.
- Berkas: migrasi `20261111_daily_brief_pg_cron.sql`, kedua workflow, rute `POST /api/cron/overlay-live`, `src/lib/overlay-cron-status.ts`, `src/lib/pantau/kesegaran.ts`, klaim kirim di `src/lib/daily-brief/service.ts`, uji, dan naskah usulan.
- Langkah: Uji ambang pada batas tepat, lalu kode. Jangan secret, jangan tulis basis hidup, jangan ubah `vercel.json`, jangan sentuh cron WhatsApp atau PR #156.
- Cara membuktikan: `npm run lint`, `npm run typecheck`, `npm test`.
- Risiko: Merge workflow Daily Brief sebelum migrasi diterapkan menghentikan kiriman otomatis. Disebut di naskah dan deskripsi PR.

## Bacaan ulang niat

Niat tidak menebak kode Tatonas, zona KRB, atau angka korban. `maritime.ok` adalah jumlah sukses, bukan boolean; kegagalan maritim dibaca dari `maritime.failed === 0`. HTTP 503 dipilih karena `pg_cron` tidak mengulang `net.http_post` hanya karena status itu, sementara `status_code` dan `curl -f` melihat kegagalan. Ambang tepat di nilai masih segar.
