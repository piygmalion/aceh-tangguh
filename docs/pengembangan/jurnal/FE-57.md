## Niat

- Tujuan: Menampilkan allowlist GIBS/FIRMS di `/peta` lewat `?nasa=` dan `?nasaDate=`.
- Berkas: URL state, toolbar, viewport, `NasaNrtOverlays.tsx`, i18n `map.*`.
- Langkah: parser terpisah dari overlays; kelompok konteks satelit; kartu FIRMS; hint awan.
- Cara membuktikan: uji isolasi i18n; `tsc`; browser jika sesi menjangkau dev server.
- Risiko: token nasa di overlays; ukuran marker resmi berubah.

## Bacaan ulang niat
