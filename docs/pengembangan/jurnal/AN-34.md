# AN-34 — naskah Histori Kejadian + Proyeksi Dampak

Agent: analis
Gelombang: 23
Status: selesai

## Niat

- Tujuan: Mengunci ganti label kartu 2 menjadi **Histori Kejadian**, dan mengganti kartu analogi menjadi **Proyeksi Dampak** berbasis histori katalog: skala (magnitudo / tinggi air), koridor (luapan sungai / kecamatan), dan skenario “jika berulang”. Bukan model PAGER/OpenQuake. Bukan angka meninggal dari skor IRBI.
- Berkas: jurnal ini; `STATUS.md`; `00-protokol.md`; `04-analis.md`; `03-frontend.md`.
- Langkah: tulis aturan; FE-28 / AN-35 menjalankan tanpa menebak korban.
- Cara membuktikan: setiap angka di kartu 3 berasal dari baris katalog atau rentang empiris; join gagal / kartu kosong = tidak diisi.
- Risiko: mengalikan skor IRBI; mengarang magnitudo; meniru PAGER sebagai angka mati; menimpa AN-32.

## Bacaan ulang niat

PAGER di playbook adalah pola rantai (intensitas × paparan × rentang), bukan izin membangun model korban. Sumber = GET `/api/kejadian/analisis` yang sama. Parser magnitudo/air/sungai hanya dari teks `penyebab`+`kronologi` yang sudah ada. Kelas IRBI hanya memilih skenario (ringan/khas/parah) dari sebaran historis, tidak menjadi rumus jiwa.

## Naskah

### 1. Label

**Perilaku.** Kartu 2 judul = Histori Kejadian (EN: Event history). Kartu 3 judul = Proyeksi Dampak (EN: Impact projection).

### 2. Kartu dampak

**Perilaku.** Payload analisis menambah `impactCards` (id, tanggal, kab, kec, penyebab, kronologi, RR/RS/RB, jiwa, KK, pengungsi). Bukan rute baru. Jangan memuat `meninggal` ke rumus proyeksi.

### 3. Parser skala dan koridor

**Perilaku.** `parseMagnitude` membaca `M5,9` / `M6,2` / `5,9 SR`. Teks “Magnitudo :” kosong = null. `53 km` bukan magnitudo. `parseWaterCm` membaca `30-80 cm` → 80; `- cm` = null. `parseSungaiLabel` membaca nama setelah “sungai”; jika hanya “luapan sungai” → label itu.

### 4. Proyeksi

**Perilaku.** Grain kabupaten jika ada dampak lokal (rumah atau jiwa/KK/pengungsi > 0); jika tidak, provinsi; jika tetap kosong, `none` tetapi pita skala tetap ditampilkan jika magnitudo terurai. Rentang = min / median / P75 / max. Skenario IRBI: RENDAH→min, SEDANG→median, TINGGI→P75 — angka tetap dari histori. Replay: kejadian terbaru dan terparah (jiwa, lalu rumah). Pita magnitudo `<5` / `5–6` / `≥6`; pita air `<50` / `50–100` / `≥100` cm. Koridor = kelompok sungai atau kecamatan.

### 5. Non-tujuan

**Perilaku.** Jangan PAGER/OpenQuake. Jangan angka meninggal dari skor. Jangan query DIBI kab×jenis. Jangan zona KRB I/II/III. Jangan mengubah `IrbiHeroPanel` / `KrbHeroPanel`. Jangan DATA-4.
